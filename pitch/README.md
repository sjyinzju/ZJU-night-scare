# 《浙大夜惊魂》路演包

## 最快使用方式

1. 打开 `飞书提交版.md`，其中已经按页放好 PPT 截图、逐页讲稿和表单用的 100 字简介。
2. 正式路演前，在本目录启动一个本地网页服务：

```bash
python3 -m http.server 4173
```

3. 浏览器打开 <http://127.0.0.1:4173/index.html>，按 `B` 确认右下角显示“B 动态”。

直接双击 `index.html` 也能看完整内容；部分浏览器会限制本地动效脚本，因此正式路演更推荐上面的本地服务方式。

## 发给别人

`file:///Users/.../pitch/index.html` 只在你自己的电脑上有效，不能直接转发。

仓库推送到 `main`、GitHub Pages 部署完成后，分享这个网址：

<https://sjyinzju.github.io/ZJU-night-scare/pitch/>

如果暂时不方便上线，就把下面三项一起压缩成 ZIP 发给对方，不能只发 `index.html`：

- `index.html`
- `motion.min.js`
- `images/`

对方解压后双击 `index.html` 即可查看。正式对外分享仍推荐 GitHub Pages 链接，手机和电脑都能直接打开。

## 操作

- `←` / `→`、滚轮或触屏：翻页
- `Esc`：打开或退出九宫格索引
- `Home` / `End`：跳到首页或末页
- `B`：切换动态/静态模式

## 文件说明

- `index.html`：9 页横向 HTML PPT
- `speaker-notes.md`：8 分钟逐页讲稿、现场演示动作和 4 分钟问答
- `飞书提交版.md`：可直接交给老师审核的 PPT＋讲稿整合版
- `outline.md`：页序、版式、图片和时间规划
- `qa/`：1600×900 的逐页定稿截图
- `images/`：PPT 与仓库 README 使用的真实游戏截图

## 现场保险

PPT 用本地服务打开；试玩页提前单独开一个标签，并停在“直接开始游戏”按钮。讲完第 9 页后只切一次标签，进行 80 秒演示。

同时准备一段 80 秒以内的本地录屏。若现场网络或游戏加载不稳定，播放录屏；录屏也失败时，回到第 4 页的三张截图口述，不要现场排错。
