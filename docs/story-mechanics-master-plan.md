# 《浙大夜惊魂》剧情、关卡布点与完整机制总案

> 用途：供剧情重写、室内建模、交互布点、音频和程序实现共同使用。  
> 依据：旧版《浙大夜惊魂-恐怖文字游戏.html》、`docs/standalone-game.html`、现行 `storyData.ts`、地图/恐怖导演配置、医学分馆模型元数据与项目路演资料。

## 1. 统一口径

### 1.1 最终采用的“双层真相”

本作不能把所有怪事都解释成鬼，也不能把所有怪事都解释成人工骗局。最终真相分两层：

1. **超自然层是真的**：1953 年死亡的戏曲演员苏婉仍以守护灵形态存在。她的歌声本来是警告；林伟有阴阳眼，白秋的“守护者人格”能感知她；医学院地下确有被旧风水格局压制的异常力量。
2. **人为犯罪层也是真的**：陈九与千绳会利用苏婉传说制造恐惧，篡改借阅与门禁记录，在楼梯间藏扩音器，重贴封条、控制灯光和监控，用仪式与心理暗示削弱受害者。林伟之死不是苏婉索命，而是陈九利用歌声、暗示和阵法促成的献祭。

玩家最终不是“打败一个鬼”，而是把怪谈拆成证据、分清守护者与加害者，并决定是否冒险切断千绳会的循环。

### 1.2 名称与角色

- 玩家主角：**张超**，计算机系大二，林伟室友，白秋男友，极阳之体，是陈九最终想占据的身体。
- 林伟：阴气重、有阴阳眼；被陈九选作第一次献祭。坠楼后可通过可收集“记忆残片”保留少量灵体视角。
- 白秋：金融系学生；存在能感知超自然的“守护者人格”。千绳会把她视为灵魂连接较弱、适合作为中介的“活尸”。剧情必须避免把现实中的精神疾病直接等同于邪祟；“双魂感知”应明确是本作独立的超自然设定。
- 张一诚：张超好友。前期因恐惧而隐瞒，后期用行动弥补，是“信任/团队”线的核心。
- 苏婉：1953 年死亡的戏曲演员、守护灵。她不是追杀者；视觉上可以可怕，但行为逻辑必须始终是警告、阻拦与留下证据。
- 杜学民：著名精神科医生，三个月前已死亡，身份被陈九冒用。
- 杜学民的师弟：暗中调查者。建议 UI 先显示“档案管理员/杜教授的师弟”，不要再让他也自称杜学民，否则反转逻辑会互相冲突。
- 陈九：千绳会成员，长期冒用杜学民身份接近白秋。他的灵魂正在衰败，计划以白秋为转移媒介，将自己转入张超的极阳身体。
- 组织统一写作：**千绳会**。README 中“千绾会”应视为笔误。

### 1.3 叙事时间

不要把全部调查伪装成一个晚上。采用“三夜一终局”的结构：

- **夜 0／三日前**：林伟独自在医学分馆听见苏婉警告，可作为通关后解锁的记忆序章。
- **夜 1／2008 年 3 月初**：医学分馆自习、林伟坠楼、警方定性、白秋警告。
- **夜 2／数日后**：论坛、张一诚、杜学民旧档案、夜探医学院、苏婉留下照片。
- **终局／5 月 9 日 23:47**：启真湖拼合证据，进入小剧场，阻止灵魂转移仪式。

章节切换用日期卡和短蒙太奇完成。校园 2.5D 地图仍是一条连续可走的“调查路线”，但时间不会因此失真。

## 2. 核心剧情线

### 序章：三日前的警告（可解锁）

林伟独自在医学分馆自习。他已连续数日梦见白衣女人站在医学院三楼窗前。23:47，馆内传来只有他听得见的戏腔。他在窗外看见苏婉；苏婉告诉他“有人在找你的朋友”“三天后带他来，但不要进入教学楼”。林伟只听清“带他来”，没有听清后半句，埋下悲剧。

### 第一章：歌声与坠楼

三天后，张超陪林伟到医学分馆。闭馆前，借阅终端打印出不存在的记录：借阅人为空、归还地点为医学院地下仓库、备注为“湖边不要回头”。票据背面受热后浮现第二句话：“不要让白秋靠近小剧场”。

林伟听见戏声，张超听不见。两人顺声进入书架区，声控灯像在前方引路。张超短暂看见没有影子的绣花鞋，林伟则看见完整的苏婉。苏婉试图让他们离开，藏在楼梯间的扩音器却播放被陈九处理过的歌声与指令。林伟精神失控，从出口冲向三百米外的医学院教学楼。

玩家经过一段很短的室外追赶抵达教学楼。无论此前选择追、等或强行拉走，林伟最终都会在陈九的暗示与阵法影响下从三楼坠落。不同选择只改变玩家是否看见白衣人伸手相救、是否取得现场线索，以及初始理智/信任，不改变核心事实。

警方录像显示林伟在窗前停留半分钟后跳下；角落里出现绣花鞋。张警官明显知情，却以“学业压力自杀”结案。陌生号码给张超发来短信：“回白沙，白秋知道下一段。”

### 第二章：白秋与旧论坛

白秋在白沙宿舍楼下等张超，警告他不要再查医学分馆、医学院和小剧场，并交出家传黄符。她知道林伟不是第一个：历届有人在歌声后失踪、失忆或走到启真湖边。玩家若耐心陪她走完雨夜，会建立“白秋羁绊”，解锁终局共同扯断红绳的路线。

回到 216 寝室后，林伟的床铺仍保留出门前的样子。半夜有人敲窗，电脑却自行亮起。旧论坛把四条传说连在一起：医学分馆歌声、医学院封条、启真湖倒影、小剧场亮灯。附件中的日记残页出现“千绳会、苏婉、1953、地下仓库”，并留下指向临湖餐厅和张一诚的坐标。

### 第三章：张一诚的隐瞒

临湖餐厅打烊后，张一诚坐在门外。他承认林伟出事那晚自己本应同行，也知道白秋正在被某个组织盯上。他最初用“白秋的病”转移话题，是因为不敢承认自己早已拿到地下仓库门禁卡。

餐厅玻璃里出现第三道人影，自动售货机和厨房托盘无故响动。张一诚最终交出带抓痕的门禁卡，并提供七年前坠楼案、旧风水图和“杜学民近三个月出入记录异常”的资料。他让张超去医学分馆内的旧办公室核对。

### 第四章：杜学民旧档案与千绳会

玩家再次进入医学分馆，但这次开放第一章被铁门挡住的档案办公室。杜学民的师弟出示死亡证明：真正的杜学民三个月前已死，仍在给白秋治疗的“杜医生”就是冒名者。旧档案显示 1953 年这里曾临时存放尸检课桌，苏婉曾试图阻止一场灵魂实验，随后死亡。

千绳会不是普通社团，而是一套让每个人只承担一小部分罪责的献祭网络。他们相信恐惧可以储存并为灵魂续命：先用传说孤立目标，再用中介“活尸”松开魂体连接，最后把衰败灵魂转移进极阳身体。陈九选择白秋作中介、张超作容器，林伟之死则用于启动阵法。

地图上的医学分馆、白沙、临湖餐厅、医学院、旧教学楼、启真湖和小剧场连成绳结。正门封条是幌子，真正通路在医学院后门和地下二层；绳结的最后一个结在小剧场。

### 第五章：夜探医学院

医学院正门感应灯不亮，电梯数字却停在 B2。玩家可以破正门、刷侧门卡或绕后门。后门有纸钱、粉笔阵、被杀死的黑猫、施工队手电和“她不是凶手”的字。这里确认陈九会主动清除能感知异常的动物。

楼内调查还原林伟最后路线：一楼有被推动过的病床与藏线，三楼窗边有鞋印和被剪过的监控线，B2 有旧档案、红绳、灵魂锚石和通向小剧场后台的废弃设备通道。玩家第一次完整见到苏婉时，她以恐怖面貌逼近，但手机自动打出：“我没有在唱，是他们逼我唱。”

苏婉用水滴倒影展示历代受害者，并把一张 1953 年照片留给玩家。照片背面写着：“若我不能出去，就让他们也不能出去。”她指向小剧场，说明自己一直守住地下力量，不让千绳会带走灵魂锚。

### 第六章：启真湖拼证

玩家在启真湖边打开证据板，把借阅小票、监控截图、论坛日记、门禁日志、黑猫阵法、杜学民死亡证明、苏婉照片和 B2 通道图按时间排序。每拼对一组，湖面倒影就少一层错误影像。

最终所有人为线索都指向陈九；所有超自然线索都证明苏婉在保护学生。湖面短暂映出小剧场：白秋被绑在舞台中央，红绳正在收紧。杜学民的师弟打来电话，要求玩家不要单独谈判，除非能让所有证据同时曝光。

### 终章：小剧场的绳结

5 月 9 日 23:47，小剧场只亮着中央追光。观众席每个座位都有一根红绳，汇向舞台。玩家先在大厅和后台完成终局准备：恢复或切断电源、找到扩音器与伪造记录的电脑、打开侧门、把证据上传到校内论坛/警方联系人。

舞台上，白秋被绑在旧木椅上，陈九承认自己从三年前就寻找极阳之体；他利用苏婉歌声吸引阴气弱的人，再用人工音源植入暗示。林伟不是“自己想跳”，而是被他推入了一个几乎无法自主退出的心理与仪式陷阱。

若建立白秋羁绊，玩家先喊她名字，使她从“守护者人格”与陈九的控制中稳定下来。白秋坦白自己一直推开张超，是怕那根线缠向他；张超回应雨夜约定。两人不再以“拯救病人”的关系面对终局，而是共同选择是否切断绳结。

最终方案由证据、道具、关系和理智共同决定：公开苏婉照片与完整证据；用门禁卡切断后台电源并制伏陈九；说服陈九放弃；带白秋逃离；或共同扯断红绳，让苏婉摧毁灵魂锚。低理智会把真相重新扭曲成精神病院的无尽循环。

## 3. 建模与布点总规则

### 3.1 点位类型

- **P 剧情点（红）**：必须触发，推进当前场景。一个剧情点只负责一个明确叙事动作，不在一个弹窗里跨越几百米或几小时。
- **E 证据点（黄）**：可检查，加入证据板并增加线索；关键证据固定出现，不做随机掉落。
- **I 道具点（蓝）**：有实体模型或明确 NPC 交付动作。
- **J 惊吓点（隐藏）**：只触发一次；触发前必须有声音、灯光、构图或可疑物作为铺垫。
- **X 出口点（绿）**：完成本区域强制剧情后才激活；出口始终对应可见的门、闸机或楼梯，不能放在无标识空气墙上。
- **H 隐藏/安全点**：桌下、柜后、厕所隔间或后台侧幕，仅在追逐段有效。

### 3.2 单点交互规范

玩家进入半径后先出现短提示，按 `E` 才正式触发；强制跳脸除外。调查镜头控制在 3–8 秒，长文本进入可暂停的剧情卡。已调查点熄灭，地面引导线只连向当前强制点。剧情点切换时保留玩家朝向，避免关闭弹窗后正对墙壁。

## 6. 完整游戏机制

### 6.1 核心循环

`地图定向 → 进入场景 → 环境观察 → 搜证/取道具 → 剧情选择 → 逃离或追逐 → 证据板推理 → 下一热点`

地图不是关卡菜单：路线上会出现鬼魂巡逻、环境事件和可选绕路；但主剧情按热点顺序开放，避免玩家提前闯入空内景。

### 6.2 操作与交互

- `WASD` 移动，鼠标观察，`Shift` 奔跑，`Ctrl` 蹲下，`E` 交互，`F` 手电，`Tab` 证据板，`Esc` 暂停。
- 跳跃只保留低矮障碍用途，不设计平台跳跃。
- 可交互物近距离才描边；当前强制点用地面引导线，证据点不直接画穿墙光柱。
- 所有门必须满足“看得见、试得了、知道为什么打不开”。锁门提示要写需要的钥匙或当前目标。

### 6.3 五项状态

| 状态 | 规则 |
|---|---|
| 理智 0–100 | 70 以上画面稳定；31–69 有轻微耳鸣/暗角；16–30 出现假路标、色差和错误倒影；1–15 会混入虚假惊吓文字；0 进入理智崩溃。强惊吓有 45 秒保护期，不能连续扣血。 |
| 体力 0–100 | 奔跑和激烈行动消耗，非追逐时缓慢恢复；低于 25 不能持续冲刺，部分硬闯选项锁定；能量饮料 +30。 |
| 线索 0–100 | 只由首次检查有效证据获得；决定玩家能否拆穿陈九、劝降和公开真相。不能靠反复交互刷分。 |
| 团队信任 0–100 | 张一诚和白秋是否愿意提供信息、等待信号或冒险救援。建议后续拆成 `baiqiuTrust` 与 `yichengTrust`；若暂不拆，文案必须说明这是“团队信任”。 |
| 白秋羁绊 0–100 | 由共伞、守约、相信她、先喊名字等行为建立；只影响关系线和共同抗控制，不替代证据要求。 |

### 6.4 证据板

证据分三列：**受害时间线、人工机关、超自然保护**。终局至少需要：

- 时间线：1953 档案、七年前坠楼、林伟监控；
- 人工机关：扩音器/接收器、门禁日志、后台控制台；
- 超自然保护：日记中苏婉记录、黑猫冷点、老照片。

玩家在启真湖完成连线后，系统不直接宣布答案，而是生成三条可在终局引用的“推理陈述”。缺少某列证据时，相应终局选项仍可尝试，但成功率或代价更差。

### 6.5 鬼魂与追逐

校园外部鬼魂沿道路网运行六状态：隐藏、巡逻、尾随、热点伏击、追逐、被驱退。剧情越后、理智越低、玩家奔跑越多，鬼的察觉距离越大。视线锥和噪声共同决定追击，不允许隔墙锁定。

- 第一章只出现远处尾随，不抓人。
- 林伟死后开放巡逻和伏击。
- 夜探医学院后开放全速追逐。
- 鬼碰到玩家先造成理智伤害并把玩家推回最近安全节点；理智归零才死亡，避免一次碰撞重跑整章。
- 室内主要使用手工编排的苏婉/陈九事件，不让校园鬼 AI 穿墙进入所有房间。
- 手电不是武器；黄符可挡一次，特定安全光区或完成当前剧情点可终止追逐。

### 6.6 惊吓导演

惊吓分三类：

1. **主线硬惊吓**：绣花鞋、林伟坠楼、病床横穿、苏婉转身、陈九拔刀；每个章节最多 1–2 个。
2. **环境软惊吓**：反射多一人、敲窗、灯闪、空座位；不连续扣大量理智。
3. **追逐反馈**：呼吸、背后脚步、被抓文字；根据距离生成。

全局规则：硬惊吓后 45 秒内禁止其他硬惊吓；同一点只触发一次；玩家视线没有朝向事件时不强制播放纯视觉跳脸；音量峰值归一，不能用音量伤害玩家。苏婉出现后的惊吓应逐渐由“她来害我”转为“她在警告我”。

### 6.7 失败、检查点与保存

- 每次进入热点、拾取关键道具、完成剧情点、进入追逐前自动保存。
- 死亡可从当前热点入口重试；保留已看文本的快速跳过，但恢复到检查点时的道具与状态，防止无限复制消耗品。
- 理智归零：进入“理智崩溃”失败；终局理智 ≤20 且已掌握大量线索时，进入“无尽噩梦”——玩家知道真相却无法再区分现实。
- 首次通关后解锁林伟、白秋、张一诚三段记忆序章；不建议像旧 HTML 一样随机替换主角，否则同一关卡需要四套相互冲突的现场逻辑。

## 8. 当前版本需要优先修正的剧情/建模错位

1. `library_sound` 后直接进入“警车已经到场”，缺少林伟从分馆冲向医学院、三楼坠落的空间过渡。应在闸机出口增加短室外追赶点。
2. 医学分馆出口目前兼作 `library_police` 剧情点，逻辑上应先是“出馆/追赶”，警察点放在医学院警戒线外。
3. 宿舍内景当前配置可拾取老照片；应移除，老照片只能在苏婉消散后获得。
4. “杜学民”与“杜学民师弟”身份混称。必须给帮助者稳定称谓，并明确死者、冒名者与调查者三者关系。
5. 当前终局移到小剧场后，旧版“医学院地下车库仪式”没有物理解释。应在 B2 增加通向小剧场后台的旧设备通道，或明确陈九已把灵魂锚转移到剧场。
6. `east-teaching` 目前是独立热点，但剧情上是医学院后门/旧教学楼的一部分。建模时应作为同一医学院关卡的另一入口，地图上可保留导航点。
7. README 写四项属性，实际已有第五项羁绊；最终 UI、文档和结局门槛应统一为五项。
8. `horrorConfig.ts` 的“李伟豪死亡后”与剧情角色林伟不一致，应统一为林伟。
9. `ending_together` 当前数据类型标为 `escape`，语义应改为最佳/真结局类型。
10. 现版本关键线索和关键道具不应继续沿用旧 HTML 的随机掉落，否则会出现模型中明明有道具、剧情状态却没拿到的情况。

## 9. 医学分馆出口（当前模型）

- 出口触发中心：**`x=0.0, z=7.84`**，半径约 **1.2 m**。
