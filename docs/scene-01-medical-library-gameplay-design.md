# 场景一：医学院图书馆内部玩法与情节设计

> 状态：实现版 v1，对应当前 3D 内景运行时。  
> 目标时长：首次游玩 12–18 分钟；熟练玩家 7–10 分钟。  
> 叙事范围：进入医学院图书馆、取得手电、调查笔记本与异常小票、拾取符咒、触发随机书架鬼影、发现灯下林伟、在返程追逐压力下逃向出口。

## 1. 设计目标

### 1.1 恐怖体验原则

本场景不是怪物竞技场，而是一个真实校园空间在午夜逐步失去规则。惊吓来源分为三层：

- **空间压迫**：低天花板、旧书架、狭窄通道、暗红灯管和暴雨前的室外黑暗，持续削弱玩家方向感。
- **规则破坏**：笔记本、小票和书架反复警告“不要回答”“不要回头”，但声音会用林伟和玩家自己的声音诱导玩家犯错。
- **有限强惊吓**：全关只保留两次高强度透明鬼影跳脸，其他恐怖由声音、灯光、红点消失、地图失真和返程追逐完成。

核心节奏是：

```text
可控调查
  ↓
异常记录
  ↓
短暂安全感
  ↓
书架强惊吓
  ↓
室外坠楼揭示
  ↓
返程压迫逃离
```

### 1.2 玩家行为目标

玩家始终需要主动靠近危险：

1. 先在出生点附近寻找手电筒。
2. 跟随唯一红点调查笔记本、小票、符咒和随机书架。
3. 在没有红点提示的黑暗区接近路灯。
4. P4 后沿原路返回，并在身后追逐压力下找到玻璃门出口。

任意时刻最多只有一个实体目标发猩红光并显示小地图红点。P4 和返程追逐是隐藏事件，不提前显示目标点。

## 2. 空间分区与动线

### 2.1 分区

| 分区 | 主要内容 | 叙事职责 |
|---|---|---|
| A 桌面区 | 出生点、随机手电桌位、笔记本桌 | 基础操作、P1 |
| B 小隔间 | 断电终端、异常借阅小票 | P2、文档阅读 |
| C 工作桌 | 旧符纸 | 一次性护命道具 |
| D 书架区 | 三个候选书位、红灯管 | P3、J1 |
| E 书架外黑暗区 | 暴雨环境、路灯、坠楼林伟 | P4、J2 |
| F 返程书架房间 | 全部红灯管不规则闪烁 | 返程追逐压力 |
| G 外墙玻璃门 | P4 后出现的出口 | 黑屏离开内景 |

### 2.2 完整游玩路径

```text
进入医学院图书馆
  ↓
出生点附近随机桌位出现手电筒
  ↓
拾取手电；笔记本成为唯一红光目标
  ↓
触碰笔记本 → P1 剧情与选择
  ↓
小隔间小票成为唯一红光目标
  ↓
拾取小票 → 文档阅读 → P2 剧情与选择
  ↓
工作桌符咒成为唯一红光目标
  ↓
拾取符咒；获得一次针对鬼影伤害的保护
  ↓
三处书架候选点按本局种子固定随机出一处
  ↓
靠近目标书 → P3 剧情与选择
  ↓
遮罩消散后触发 J1 书架鬼影跳脸
  ↓
进入书架外黑暗区；不显示红点
  ↓
接近路灯触发 P4：J2 + “砰”声 + 林伟显形 + 猩红路灯
  ↓
P4 强毛玻璃剧情与选择
  ↓
出口玻璃门激活；小地图显示出口红线
  ↓
玩家返回书架房间，红灯持续闪烁，身后鬼影逐渐逼近
  ↓
若停留或逆行过久，被身后压力命中：优先消耗符咒，否则扣理智
  ↓
触碰玻璃门 → 黑屏 → 返回校园 2.5D 地图
```

## 3. 道具与目标

### I01 手电筒

- 每局从出生点附近三个桌面锚点中选择一个。
- 随机结果由 `sessionSeed` 和 `pickup:flashlight` 固定；同一局重进或重载内景不会重新抽取。
- 不进入红点剧情链；玩家通过初始弱光和桌面反光发现它。
- 拾取后解锁真实手电光锥，并允许部分选项显示更多线索。

### I00 笔记本

- 第一处强制剧情实体。
- 触碰后关闭红光和小地图红点，进入 P1。
- 内容建立三条恐怖规则：听见唱名不要回答、听见熟人从背后叫你不要回头、23:47 后不要相信出口。

### I02 异常借阅小票

- P1 完成后激活。
- 拾取时先进入小票文档阅读，再进入 P2 剧情与选择。
- 票面关键信息：
  - 借阅人为空；
  - 索书号 `R-1953 / 戏曲病理档案`；
  - 归还地点“医学院地下仓库”；
  - 时间 `23:47`；
  - 背面压痕“湖边不要回头”“听见唱名时，不要回答”。

### I03 符咒

- P2 完成后激活。
- 拾取后推进到 P3 书架阶段。
- 作为一次性保护使用：当返程追逐或鬼影造成较强理智伤害时，统一伤害管线优先消耗符咒。
- 符咒不取消恐怖事件，只把一次失败从死亡/重伤转换成可继续逃离的警告。

## 4. 四个剧情点

### P1「十点以后，有人在唱」

**实体**：笔记本。  
**前置**：进入内景。  
**触发**：玩家触碰发红光的笔记本。

剧情功能：

- 交代林伟连续三天听见戏腔。
- 引入 `23:47`、绣花鞋、借阅小票和“不要回答”。
- 将玩家目标从桌面区引向小隔间。

选项方向：

| 选择倾向 | 结果 |
|---|---|
| 仔细核对日期与名字 | 理智小幅下降，线索增加最多 |
| 用手机拍下末页 | 体力小幅下降，保留证据 |
| 合上笔记本离开 | 理智略回升，但线索较少 |

### P2「不存在的最后一条记录」

**实体**：借阅小票。  
**前置**：P1 完成。  
**触发**：玩家拾取发红光的小票。

剧情功能：

- 断电打印机自行运转。
- 终端黑屏映出玩家身后的人脸。
- 小票将图书馆与医学院地下仓库连接起来。
- 背面提示符咒位置，为下一目标建立合理动机。

选项方向：

| 选择倾向 | 结果 |
|---|---|
| 与笔记本时间比对 | 获得时间线关联 |
| 用手电检查压痕 | 需要手电；发现更多警告 |
| 收进口袋离开隔间 | 风险较低，线索较少 |

### P3「没有影子的脚步」

**实体**：随机选中的旧书。  
**前置**：拾取符咒。  
**触发**：玩家靠近本局被抽中的书架点。

随机规则：

- 三处候选书架点来自 `scene01.meta.json`。
- 选择由 `sessionSeed` 和 `story:library_shelf` 固定。
- 同一局不会因为内景重建而换位置。

剧情功能：

- 让脚步声模仿玩家移动。
- 书架缝隙中出现眼睛、湿发和白衣边缘。
- 林伟的声音从房间外引导玩家离开。
- 选择消散后延迟触发 J1，不与剧情遮罩同帧重叠。

J1 表现：

- 使用 `library-shelf-ghost.png`。
- 上下文文字来自 `library_shelf` 池。
- 快速放大、震屏、红闪、血滴和短暂理智伤害由统一 `JumpscarePipeline` 处理。

### P4「灯下的人」

**实体**：路灯与坠楼林伟。  
**前置**：P3 完成。  
**触发**：玩家进入隐藏距离触发半径；无红点、无小地图提示。

演出时间轴：

1. 玩家进入书架外黑暗区，坠楼人物隐藏，路灯关闭。
2. 接近路灯触发半径。
3. 同一时刻执行 J2、坠落“砰”声、林伟显形、猩红路灯开启。
4. 强毛玻璃剧情遮罩出现，玩家只能隐约看见灯与地面人形。
5. 选择完成后遮罩解除，玩家首次清楚看见林伟。
6. 出口玻璃门激活，小地图显示出口红线。

J2 表现：

- 使用 `library-fall-ghost.png`。
- 叠加程序化坠落冲击声 `playImpactBang()`。
- 不再额外扣理智，避免与 P4 剧情结算重复惩罚。

## 5. 返程追逐压力

P4 后玩家必须从黑暗区返回书架房间，再走向玻璃门。此段不是完整鬼怪 Boss 战，而是一段短追逐压力：

```text
P4 完成
  ↓
玩家离开室外黑暗区后再进入书架房间
  ↓
红灯管进入不规则闪烁
  ↓
身后出现看不见的红色逼近光源
  ↓
玩家持续向出口移动：压力保持在身后
  ↓
玩家停留、回走或拖延：压力逐渐接近
  ↓
过近时触发 ghost_close 惊吓与理智伤害
  ↓
符咒存在时优先消耗符咒并继续流程
```

实现目标：

- 玩家感受到“她在背后追”，但仍能看清逃生路线。
- 不强行旋转镜头，不剥夺玩家方向控制。
- 不制造额外可见 3D 鬼模型，避免与透明 PNG 跳脸视觉体系冲突。
- 接近出口后压力关闭，防止玩家在门前被反复打断。

## 6. 出口状态机

```text
SEALED_WALL
  ├─ P4 前：玻璃门与出口 void 隐藏
  └─ 小地图不显示出口

P4_COMPLETED
  ├─ 当前剧情变为 dorm_baiqiu
  ├─ phaseVisuals 显示 library_exit_door / library_exit_void
  └─ 小地图显示出口红线

RETURN_PURSUIT
  ├─ 玩家返回书架区
  ├─ 红灯闪烁
  └─ 身后压力逼近

EXIT_AVAILABLE
  └─ 玩家触碰玻璃门触发黑屏

EXITED
  └─ 回到校园 2.5D 地图，下一目标为白沙宿舍区
```

出口不能是空气触发区。玩家必须看到玻璃门/门洞状态变化，并通过真实门位置离开。

## 8. 验收流程

完整 QA 路径：

```text
手电筒
  → 笔记本 P1
  → 小隔间小票与文档阅读
  → P2 选择
  → 符咒
  → 随机书架 P3
  → J1 书架跳脸
  → 黑暗区 P4 距离触发
  → J2 + 砰声 + 林伟显形
  → P4 选择
  → 返回书架房间红灯闪烁
  → 返程追逐压力
  → 玻璃门出口
  → 回到校园地图
```

必要验证：

1. `npm run build` 通过。
2. 同一局重复挂载内景时，手电位置和书架目标保持不变。
3. P3 后 J1 不在剧情遮罩仍覆盖时触发。
4. P4 触发前没有小地图红点；P4 后出口红线出现。
5. 返程停留过久会触发身后压力，符咒可抵挡一次较强伤害。
6. 触碰出口后黑屏离开，并进入白沙宿舍区后续流程。

## 9. 后续可加强项

- 将返程追逐的脚步、呼吸和耳鸣拆成独立空间音频层。
- 在减少动态效果设置中降低 J1/J2 震屏幅度和返程闪烁频率。
- 为小票文档阅读补充纸张焦黑消散动画。
- 将“不要回头”的玩家行为检测做成可选软惩罚：短时间快速回头只扣理智，不改变主线。
