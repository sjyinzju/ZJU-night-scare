# 第五章：医学院教学楼内部玩法与情节设计

> 状态：细化稿 v1，基于原著 PDF 与当前游戏已完成流程。  
> 目标时长：首次游玩 10–14 分钟；熟练玩家 6–8 分钟。  
> 叙事范围：离开农医馆与白沙宿舍线索后，进入医学院教学楼，调查六层坠楼窗、后门与地下仓库，确认“古装女/苏婉不是凶手”，取得 1953 老照片并指向启真湖与小剧场。

## 1. 地点口径

### 1.1 农医馆与医学院必须分开

本项目后续统一采用以下口径：

| 项目地点 | 原著对应 | 游戏职责 |
|---|---|---|
| 农医馆 | 原著开场“医学院图书馆/医学分馆” | 第一章自修、借阅记录、书架异响、离馆后引出坠楼 |
| 医学院 | 原著“医学院教学楼/教学楼地下一层车库/六层走廊” | 李伟豪/林伟坠楼地点、古装女目击、地下仓库、苏婉证据 |

农医馆是开场调查空间；医学院是后续更危险的教学楼与地下空间。两者距离很近，但不是同一栋建筑，不能把农医馆的书架玩法直接当作医学院内部玩法。

### 1.2 原著关键依据

原著前段给出的医学院核心事实：

- 张超和李伟豪先在西南角的医学院图书馆自修。
- 图书馆关门后，两人来到后方约 300 米的教学楼地下一层自行车库。
- 教学楼共六层，夜里走廊灯全灭。
- 李伟豪听见张超听不见的歌声，跑上楼。
- 张超在窗边听见坠落闷响，看到一楼露台上的李伟豪。
- 监控录像显示李伟豪走到六层窗边跳下，几分钟后画面死角出现一双脚和白裙。
- 第二天张超在论坛看到“西区古装女”目击帖，地点集中在医学院后方小路、沼泽田和医学院教学楼。
- 张超再次来到医学院教学楼，看到六层窗口背对窗户的白衣长发女人，并在楼内听见若有若无的歌声。
- 白秋明确劝张超不要再去医学院。

## 2. 当前游戏已完成前置

医学院章节不能从零开始，而是承接当前已完成内容：

```text
农医馆场景一
  → 借阅小票：归还地点“医学院地下仓库”
  → 白沙宿舍：论坛旧帖、林伟痕迹、符纸与追逐
  → 临湖餐厅：张一诚交出门禁卡
  → 杜学民旧档案：千绳会、1953、地下仓库、医学院路线
  → 医学院入口：封条、B2、电梯、后门
```

因此医学院内部玩法的目标不是重复“找书架红点”，而是把农医馆、白沙和档案线索全部落到同一座教学楼里：

- 还原林伟/李伟豪最后路线。
- 找到人为操控歌声与监控的证据。
- 第一次完整面对苏婉，并理解她是警告者。
- 取得真正的 1953 老照片原件。
- 打开前往启真湖证据拼合和小剧场终局的路线。

## 3. 空间分区

| 分区 | 主要内容 | 叙事职责 |
|---|---|---|
| A 医学院正门 | 封条、施工告示、B2 电梯数字 | 确认入口异常 |
| B 地下一层车库 | 自行车库、上行楼梯、轮子滚动声 | 对应原著“图书馆后 300 米教学楼地下一层” |
| C 六层走廊 | 坠楼窗口、监控死角、三间锁门教室 | 还原林伟坠楼路线 |
| D 医学院后门 | 纸钱、粉笔阵、黑猫尸体、施工队手电 | 当前游戏已接入 `teaching_back` |
| E B2 仓库门 | 门禁卡、配电箱、地下仓库门 | 连接小票“归还地点” |
| F 地下仓库 | 红绳、旧病床、1953 名册、灵魂锚石痕迹 | 证明人为层与仪式层 |
| G 苏婉显形点 | 水迹、白衣背影、手机自动文字 | 反转“她不是凶手” |

当前程序化 `medical` 房间已经具备：病床、储物柜、地下仓库门、剧情触发点、苏婉 NPC 显形与照片奖励。后续强化应优先复用这些结构，不另起一套平行流程。

## 4. 完整游玩路径

```text
抵达医学院正门
  ↓
查看封条、电梯 B2、施工告示
  ↓
选择正门 / 侧门门禁 / 绕后门
  ↓
后门调查黑猫、粉笔阵、施工队手电
  ↓
进入教学楼地下一层车库
  ↓
听见病床轮子声，从地下一层引向楼梯
  ↓
上到六层走廊
  ↓
检查坠楼窗口、剪线痕迹、监控死角
  ↓
听见若有若无的戏腔，看到白衣背影转入走廊尽头
  ↓
进入 B2 地下仓库门前
  ↓
刷门禁卡或完成配电小谜题打开仓库
  ↓
调查红绳、旧名册、灵魂锚石底座
  ↓
苏婉完整显形，触发 J-hard
  ↓
手机自动出现“我没有在唱，是他们逼我唱”
  ↓
玩家选择询问 / 用黑猫毛发感知 / 逃跑
  ↓
若留下，苏婉交出 1953 老照片原件
  ↓
离开医学院，前往启真湖拼合证据
```

## 5. 剧情点设计

### M-P01「医学院封条」

**位置**：医学院正门。  
**已有关联场景**：`medical_entry`。

功能：

- 承接农医馆小票上的“医学院地下仓库”。
- 让玩家看到封条被重新贴过，电梯停在 B2。
- 强调医学院教学楼和农医馆不是同一地点。

选择：

| 选项 | 玩法结果 |
|---|---|
| 从正门进入 | 更快进入走廊，但理智与体力损失更高 |
| 用门禁卡绕侧门 | 需要张一诚给的门禁卡，线索更清晰 |
| 绕到旧教学楼后面 | 进入后门黑猫线，获得额外感知道具 |

### M-P02「后门与黑猫」

**位置**：医学院后门。  
**已有关联场景**：`teaching_back`。

功能：

- 使用原著“西南角、沼泽田、医学院阴气重”的空间氛围。
- 黑猫死亡说明有人主动清除能看见异常的动物。
- 施工队手电与原著张超购买强光手电的行为对应，作为内景照明补给。
- 粉笔字“她不是凶手”提前埋下苏婉反转。

获得：

- `flashlight`：若玩家此前漏掉手电，这里补发，不让医学院内景卡死。
- `cat_hair`：后续用于辨认苏婉指向的真实位置。

### M-P03「六层坠楼窗」

**位置**：医学院六层走廊。  
**当前状态**：需要在后续 3D 点位中补强。

玩法：

- 走廊两侧教室全部锁门，窗外能看到农医馆和未开发沼泽田。
- 玩家靠近坠楼窗口时，声音从地下一层、三层、六层之间来回跳。
- 检查点位包括：
  - 窗框抓痕；
  - 被剪过的监控线；
  - 地面湿鞋印；
  - 暖气片后的旧音频接收器。

结果：

- 获得“人为诱导歌声”的第一组证据。
- 解锁 B2 仓库门红点。

### M-P04「B2 地下仓库」

**位置**：地下仓库门后。  
**当前状态**：程序化内景已存在地下仓库门和储物柜，可继续扩展。

玩法：

- 门禁卡可直接打开门；没有门禁卡时需要走配电小谜题。
- 配电谜题不应复杂，目标是营造恐怖压力：
  - 先合上局部电源；
  - 走廊灯亮起两秒；
  - 某扇教室门内传来椅子拖动声；
  - 选错开关会熄灯并触发一次软惊吓，不直接死亡。

证据：

- 1953 名册；
- 红绳残段；
- 灵魂锚石底座；
- 通向小剧场后台的旧设备通道图；
- 与小票索书号 `R-1953` 对应的旧档案。

### M-P05「走廊尽头的女人」

**位置**：二楼/B2 回程转角或六层走廊尽头。  
**已有关联场景**：`ghost_choice`。

演出：

1. 玩家先看到白衣背影或长发挂在窗前，呼应原著六层窗口。
2. 走近后歌声停止。
3. 她快速从走廊尽头横向掠过，玩家需要主动追过去。
4. 再次靠近时触发 J-hard：白衣古装女转身，黑瞳、无影、水迹、短震屏。
5. J-hard 后立刻给出保护性信息，避免玩家误以为她只是杀人鬼。

核心文本：

```text
我没有在唱。
是他们逼我唱。
```

选择：

| 选项 | 结果 |
|---|---|
| 出声问她是谁 | 理智下降较多，获得苏婉身份线索 |
| 用黑猫毛发感知她指向的位置 | 需要 `cat_hair`，线索最多 |
| 转身逃跑 | 可继续主线，但错过照片原件和部分解释 |

### M-P06「苏婉的照片」

**位置**：苏婉消散后的地面。  
**已有关联场景**：`stand_ground`。

功能：

- 老照片必须在医学院获得，不能放在白沙宿舍直接掉落真品。
- 照片正面：苏婉站在旧教学楼/浙江医学院前。
- 背面：1953 年、她留下的警告，以及小剧场方向。
- 它是后续启真湖证据板和终局公开真相的核心道具。

## 6. 惊吓与玩法节奏

### 6.1 强惊吓数量

医学院内部建议只有一次强跳脸：

| 编号 | 位置 | 内容 | 目的 |
|---|---|---|---|
| M-J01 | 苏婉转身 | 白衣古装女近距离显形 | 让玩家害怕她 |

随后立即用手机文字与照片反转，让玩家意识到她不是凶手。医学院的恐怖重点不是继续堆跳脸，而是让玩家在证据层面理解“可怕的外表不等于加害者”。

### 6.2 软惊吓

- 车库里病床轮子声经过，但光照不到人。
- 六层窗外白影短暂停住，玩家靠近后消失。
- 教室防盗门内有桌椅拖动声。
- B2 配电错误后，所有灯同时熄灭一秒。
- 手机备忘录自动输入，输入光标停在玩家名字后面。

### 6.3 道具使用

| 道具 | 在医学院中的用途 |
|---|---|
| 手电筒 | 看清抓痕、监控线、B2 名册；没有也可通关但线索减少 |
| 门禁卡 | 打开侧门、B2 仓库门，留下门禁日志证据 |
| 黑猫毛发 | 显示苏婉真正指向的位置，区分幻象和真实线索 |
| 符咒 | 抵挡一次强理智伤害，不阻止剧情惊吓 |
| 老照片 | 医学院取得，启真湖与终局关键证据 |

## 8. 验收流程

```text
完成农医馆与白沙线
  → 张一诚取得门禁卡
  → 杜学民旧档案指向医学院
  → 医学院入口封条
  → 后门黑猫与手电
  → 进入医学院内景
  → 六层坠楼窗证据
  → B2 地下仓库证据
  → 苏婉显形与 J-hard
  → 获得 1953 老照片
  → 前往启真湖
```

验收重点：

1. 地图与 UI 中“农医馆”和“医学院”始终是两个地点。
2. 农医馆小票指向医学院地下仓库，但不把两个空间合并。
3. 医学院玩法要回收原著的地下一层车库、六层走廊、古装女、沼泽田、白秋劝阻。
4. 老照片真品只在医学院获得。
5. 苏婉先吓人，再给证据，保证“她不是凶手”的反转成立。
