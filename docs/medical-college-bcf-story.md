# 医学院 B / C / F 剧情接入

> 当前分支：`medical-school`；剧情结构参考 `15c2260181a0322a388ca0838391fcfbfb82e898` 的 B / C / F 初稿。
> 范围：只接已有建模的 **C 顶层 / 六层走廊**、**B 地下一层车库**、**F 地下仓库**。
> 职责：本文与 `storyData.ts` 记录剧情事实；本文末尾的玩法是候选设计，尚未写入运行时状态机。

## GLB 实测结构

源资产为 `public/models/interiors/medical-school/medical.glb`。运行时由
`tools/build_medical_segments.py` 生成三段资产：

| 分段 | 文件 | 本地大小 | 加载时机 |
|---|---|---:|---|
| 顶层教学走廊 | `medical-top.glb` | 约 7.8 MB | 进入医学院时加载 |
| 中层停车场 | `medical-garage.glb` | 约 9.9 MB | 顶层显示完成后后台预载 |
| 地下仓储/实验区 | `medical-basement.glb` | 约 12.7 MB | 剧情进入停车场后后台预载 |

三个文件不会同时解析或挂入 Three.js 场景；预载只缓存下一段的二进制数据。未来楼梯黑屏切换重建内景时，再把缓存段解析为场景。Blender 与 GLB 数据检查结果：

- 单个完整 GLB，约 16.9 MB；1 个场景、2,009 个节点、1,061 个网格、243 个原始材质、215 张纹理，无动画。
- 整体约 `58 × 104 × 17.9 m`，是顶层教学区、地下停车区和更深地下房间纵向叠放的复合场景，不是六个完整教学楼层逐层建模。
- 顶层是长条教学区：中央长走廊、连续房门、窗和若干横向连接/转角。当前出生点位于中央走廊东端附近，面向西侧长纵深。
- 东侧主楼梯间有连续三段楼梯与平台，可从顶层下到停车层并继续下探；深层仓储/实验区内另有一座短楼梯，只负责更深区域之间的连接。
- 停车层有大面积柱网、停车位、长行车通道、侧房和铁门；模型中可识别到名为 `地下停车场03` 的分组。
- 深层区域由更窄的仓储、柜体、设备、病床/操作台和隔帘空间构成，空间密度明显高于停车场。
- 门、铁门和楼梯都只有静态网格；GLB 没有门动画、电梯动画或现成的玩法锚点。

顶层分段额外包含 `medical_notice_board_*` 公告栏节点。公告栏位于出生点右前方、非死路方向，安装在最近两扇门之间的墙面，不遮挡门洞。源 FBX 是 Blender 2.66 的 ASCII FBX，现代 Blender 无法直接导入；构建脚本按原 Frame / Front 两部分尺寸重建几何，并使用同目录的木框、软木和凹凸贴图。

现阶段医学院只用于模型审阅。旧的二维 XZ 碰撞投影无法表达上下重叠楼层，会把顶层走廊误判成实墙，因此正式多层碰撞、楼梯行走和剧情触发点都留到玩法方案确定后再做。

  → C medical_window

## 各区剧情

### C 顶层 / 六层走廊 · `medical_window`

小说：六层空走廊、三间锁门教室、中间坠楼窗、3–5 秒戏腔、白影转弯下楼。

要发生：

- 玩家进入 GLB 后出生在顶层，而不是车库。
- 检查窗框抓痕、湿鞋印、被剪监控线。
- 鞋印、红绳、白影和戏腔都指向向下的楼梯。
- 只还原现场并建立下行方向，不在这里展开苏婉。

正文刻意写短。顶层走廊留给玩法。

### B 地下一层车库 · `medical_garage`

小说：图书馆后 300 米，教学楼地下一层自行车库；林伟从这里上楼。车库连通东侧其他楼。

要发生：

- 玩家从顶层逐层下行后抵达这里，确认林伟当晚走的是反方向。
- 病床轮子声、轮痕与六层鞋印发生呼应。
- 深处车道没有尽头，东西可以从下面走掉。
- 疏散图上的涂黑终点把路线继续引向地下仓库。

玩法不要在这里收光。吓人靠声音、纵深和连通感。

### F 地下仓库 · `medical_vault` / `ghost_choice` / `stand_ground`

HTML + 现行案：小票归还地点、1953、红绳、旧鞋、苏婉反转、老照片。

要发生：

- 刷开门禁卡，对上 R-1953 名册和小剧场通道图。
- 墙角旧绣花鞋（鞋尖朝墙）。
- 苏婉先吓人，手机出现「我没有在唱。是他们逼我唱。」
- 留下才拿到 1953 老照片；跑则线索少，仍去启真湖。

终局仪式不要放回仓库。这里只证明锚石被挪走、通道通向小剧场。

## 分层玩法候选（未实现）

三层分别只强化一个核心动作，避免和农医馆的拾取链、白沙宿舍的照片异变与追逐重复：

| 楼层 | 核心动作 | 恐惧来源 | 剧情产出 |
|---|---|---|---|
| 顶层教学区 | 观察并复原现场 | 走廊的视觉矛盾、灯光次序、玻璃反射 | 林伟不是主动跳窗，线索指向楼下 |
| B1 停车场 | 听声辨路 | 柱网遮挡、错误回声、看不见的病床 | 林伟从地下向上，车库连着仓库 |
| 地下仓库 | 对证并承受接近 | 隔帘、反重力水迹、苏婉逼近 | R-1953、苏婉反转、照片与剧场通道 |

### 顶层：最后十七秒

1. 玩家在公告栏看到一张被撕去下半部分的值班表，以及三间被圈出的教室编号。公告栏只提供调查顺序，不直接给答案。
2. 三间教室不需要进入。玩家透过门窗观察室内时，每间都留下一个互相矛盾的“最后十七秒”：窗边抓挠声、被剪断的监控杂音、鞋底踏水声。
3. 玩家用手电以低角度扫地，湿鞋印才显形；直射时反而看不见。鞋印从窗边返回楼梯，推翻“主动跳窗”。
4. 每确认一项证据，一段方形红灯便按当晚事件的逆序熄灭。熄灭方向不是目标指引，而是在倒放林伟最后走过的路线。
5. 中段窗户只在玻璃反射里多出第二个人。玩家回头时走廊为空；再次看玻璃，白影已经位于下一层平台。这里不做跳脸。
6. 三项证据齐全后，病床轮声第一次盖过戏腔，楼梯口红绳自行绷紧。玩家主动走向楼梯，进入日后实现的黑屏切层。

失败不重置流程：错误观察只降低理智、改变下一次声源位置，避免把恐怖调查变成试错题。

### B1 停车场：回声没有跟着你

1. 进入时只看见最近一排柱号，小地图不显示目标；玩家走过的车道才逐段显现，形成有限制的“手绘地图”。
2. 看不见的病床沿柱网移动。轮声有真实声源和延迟回声：最响的方向会把玩家带回原柱，轮痕消失的方向才是正确路线。
3. 每到岔路，玩家可让手电扫过悬挂铁链制造一次可控声响。病床声会回应，玩家据回应时间判断通道是否连通；这让声音成为主动调查工具，而非纯提示。
4. 经过同一根柱子第二次时，柱号变成六层教室号，暗示空间正在把上下两层叠在一起；第三次才出现短促近距离惊吓，避免重复循环拖时长。
5. 中段设置一个无敌人、但必须横穿开阔车道的“暴露段”。远处白影始终与玩家保持一列柱子的距离，只在玩家停步时继续移动。
6. 玩家最终在轮痕、鞋印和疏散图红线的交点找到未标注铁门，确认林伟当晚来自地下而不是窗外。

本层不做传统追逐和死亡怪物；压力来自听觉判断、开阔暴露感以及空间回环。

### 地下仓库：让她走到面前

1. 玩家用门禁卡进入，隔帘后依次出现病床、空床、解剖台；顺序每次回头都会改变，但关键证据位置保持稳定，避免随机化破坏叙事逻辑。
2. 玩家把借阅小票 R-1953 与铁柜抽屉、名册和通道图对证。不是收集多个新道具，而是让已有道具获得新含义。
3. 反重力水迹穿过三个隔帘。错误隔帘后没有怪物，只出现属于其他受害者的滴水倒影；正确隔帘后才是鞋尖朝墙的绣花鞋。
4. 苏婉显形后取消普通选项框片刻。她用手机备忘录提出三句残缺问题，玩家用手电照向“名册 / 空底座 / 小剧场通道图”作答，把剧情选择放回三维空间。
5. 最终考验不是逃跑：玩家需要在苏婉缓慢靠近时保持原地、持续看着她，直到手机出现“我没有在唱”。移动或转身不会死亡，但会进入现有逃跑分支并失去照片。
6. 坚持留下时，她依次指回头顶窗户、车库轮痕、红绳和空底座，完成整章呼应；照片落下后所有病床声同时停止，只剩远处拉幕声。

### 节奏控制

- 顶层约 8–10 分钟：低威胁调查，建立规则。
- 停车场约 10–12 分钟：用声音制造方向焦虑，中段给一次安静缓冲。
- 仓库约 10–12 分钟：证据密度最高，以“克制不逃”收束而不是追逐。
- 跳脸只保留苏婉首次完整显形一次；其他恐惧依赖声源、反射、灯光和空间变化。
- 所有异常必须能回扣红绳、鞋印、病床、1953 或小剧场，不生成与主线无关的随机鬼事件。
