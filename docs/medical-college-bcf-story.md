# 医学院 B / C / F 剧情接入

> 当前分支：`medical-school`；剧情结构参考 `15c2260181a0322a388ca0838391fcfbfb82e898` 的 B / C / F 初稿。
> 范围：只接已有建模的 **C 顶层 / 六层走廊**、**B 地下一层车库**、**F 地下仓库**。
> 职责：本文与 `storyData.ts` 只负责剧情；玩法由对方在空旷的停车场 / 六层布置。

## GLB 实测结构

源资产为 `public/models/interiors/medical-school/medical.glb`。运行时由
`tools/build_medical_segments.py` 生成三段资产：

| 分段 | 文件 | 本地大小 | 加载时机 |
|---|---|---:|---|
| 顶层教学走廊 | `medical-top.glb` | 约 7.8 MB | 进入医学院时加载 |
| 中层停车场 | `medical-garage.glb` | 约 9.9 MB | 顶层显示完成后后台预载 |
| 地下仓储/实验区 | `medical-basement.glb` | 约 12.7 MB | 剧情进入停车场后后台预载 |

三个文件不会同时解析或挂入 Three.js 场景；预载只缓存下一段的二进制数据。未来楼梯黑屏切换重建内景时，再把缓存段解析为场景。Blender 与 GLB 数据检查结果：

- 单个完整 GLB，约 16.9 MB；1 个场景、2,009 个节点、1,061 个网格、243 个原始材质、215 张纹理，无动画。
- 整体约 `58 × 104 × 17.9 m`，是顶层教学区、地下停车区和更深地下房间纵向叠放的复合场景，不是六个完整教学楼层逐层建模。
- 顶层是长条教学区：中央长走廊、连续房门、窗和若干横向连接/转角。当前出生点位于中央走廊东端附近，面向西侧长纵深。
- 东侧主楼梯间有连续三段楼梯与平台，可从顶层下到停车层并继续下探；深层仓储/实验区内另有一座短楼梯，只负责更深区域之间的连接。
- 停车层有大面积柱网、停车位、长行车通道、侧房和铁门；模型中可识别到名为 `地下停车场03` 的分组。
- 深层区域由更窄的仓储、柜体、设备、病床/操作台和隔帘空间构成，空间密度明显高于停车场。
- 门、铁门和楼梯都只有静态网格；GLB 没有门动画、电梯动画或现成的玩法锚点。

顶层分段额外包含 `medical_notice_board_*` 公告栏节点。公告栏位于出生点右前方、非死路方向，安装在最近两扇门之间的墙面，不遮挡门洞。源 FBX 是 Blender 2.66 的 ASCII FBX，现代 Blender 无法直接导入；构建脚本按原 Frame / Front 两部分尺寸重建几何，并使用同目录的木框、软木和凹凸贴图。

现阶段医学院只用于模型审阅。旧的二维 XZ 碰撞投影无法表达上下重叠楼层，会把顶层走廊误判成实墙，因此正式多层碰撞、楼梯行走和剧情触发点都留到玩法方案确定后再做。

## 空间口径

| 分区 | 模型 | 剧情密度 | 对应场景 ID |
|---|---|---|---|
| C 六层走廊 | 已有 | 低，留玩法 | `medical_window` |
| B 地下一层车库 | 已有 | 高，吓人 | `medical_garage` |
| F 地下仓库 | 已有 | 高，吓人 + 证据 | `medical_vault` → `ghost_choice` → `stand_ground` |

不做 3D 的：正门广场、后门黑猫、B2 配电谜题、小剧场终局。后门仍是进楼前的室外文本 `teaching_back`。

## 游玩顺序

```text
室外 medical_entry（可先走 teaching_back）
  → C medical_window
  → 沿楼梯逐层下行
  → B medical_garage
  → F medical_vault
  → F ghost_choice（苏婉显形）
  → F stand_ground（1953 照片）
  → 离开，去启真湖
```

三条入口只改变进 C 之前是否拿到手电 / 黑猫毛发，不改变 C → B → F。

## 各区剧情

### C 顶层 / 六层走廊 · `medical_window`

小说：六层空走廊、三间锁门教室、中间坠楼窗、3–5 秒戏腔、白影转弯下楼。

要发生：

- 玩家进入 GLB 后出生在顶层，而不是车库。
- 检查窗框抓痕、湿鞋印、被剪监控线。
- 鞋印、红绳、白影和戏腔都指向向下的楼梯。
- 只还原现场并建立下行方向，不在这里展开苏婉。

正文刻意写短。顶层走廊留给玩法。

### B 地下一层车库 · `medical_garage`

小说：图书馆后 300 米，教学楼地下一层自行车库；林伟从这里上楼。车库连通东侧其他楼。

要发生：

- 玩家从顶层逐层下行后抵达这里，确认林伟当晚走的是反方向。
- 病床轮子声、轮痕与六层鞋印发生呼应。
- 深处车道没有尽头，东西可以从下面走掉。
- 疏散图上的涂黑终点把路线继续引向地下仓库。

玩法不要在这里收光。吓人靠声音、纵深和连通感。

### F 地下仓库 · `medical_vault` / `ghost_choice` / `stand_ground`

HTML + 现行案：小票归还地点、1953、红绳、旧鞋、苏婉反转、老照片。

要发生：

- 刷开门禁卡，对上 R-1953 名册和小剧场通道图。
- 墙角旧绣花鞋（鞋尖朝墙）。
- 苏婉先吓人，手机出现「我没有在唱。是他们逼我唱。」
- 留下才拿到 1953 老照片；跑则线索少，仍去启真湖。

终局仪式不要放回仓库。这里只证明锚石被挪走、通道通向小剧场。
