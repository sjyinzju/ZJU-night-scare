# 终章：小剧场密室、放映演绎与多结局策划

> 状态：简化修订稿。  
> 目标：把小剧场做成与农医馆、白沙宿舍相近体量的正常内景关卡，控制建模、布景、机关和剧情量。  
> 依据：原著终章、`story-mechanics-master-plan.md`、现行剧情数据、白沙宿舍与医学院内景策划。  
> 当前不锁具体坐标；正式模型完成后再填写元数据锚点。

## 1. 本次简化原则

1. 小剧场只分为三块空间：**门厅/票务台、观众席与舞台主厅、后台密室**。
2. 后台、化妆区和短通道合并成一个密室区域，不再制作多个独立房间、楼层或舞台下空间。
3. 全关只保留 **4 个主剧情点**，另有一次短追逐，不把每个机关都做成长剧情弹层。
4. 新增实体道具只保留两件：**旧胶片盒**和**备用保险丝**。其他分支继续使用玩家前面已有的道具和状态。
5. 不做“每个座位都有红绳”“每个座位坐一个人”“大量小型证物”等高成本布景。
6. 复杂往事、受害者、旧现场和超自然画面主要由镜面图片与老式放映机图片表现。
7. 主厅第一次进入与追逐后返回使用同一空间，通过幕布、灯光、人物显隐和投影变化制造“完全变了样”的感觉。

建议首次游玩时长 20–30 分钟：

```text
门厅取胶片 3–4 分钟
主厅第一次观察 2–3 分钟
后台密室 8–12 分钟
短追逐 30–50 秒
主厅最终演绎与选择 6–9 分钟
```

## 2. 终章剧情目标

终章只集中回答三件事：

- 苏婉的歌声原本是警告，陈九把它剪接成了诱导和喊名声。
- 林伟不是被苏婉索命，而是被陈九布置的声音、现场机关和心理暗示推向坠楼。
- 白秋不是仪式道具，也不是等待张超替她决定的人；最终能否共同完成“最后一幕”，取决于玩家此前是否真正相信和尊重她。

主题句：

> 陈九把所有受害者写进了一出鬼戏。玩家最后要做的，是让他们重新拥有名字。

## 3. 前文需要保持的统一口径

- 真正的杜学民已经死亡；陈九曾冒用他的身份接近白秋；启真湖提供帮助的是杜教授师弟/档案调查者。
- 白秋的守护者状态属于本作超自然设定，不能简单写成现实精神疾病导致暴力，也不能在结局中写成“被爱情治好”。
- 护身符在农医馆取得，白秋在宿舍楼下辨认并说明用法，不再发第二枚。
- 医学院取得的苏婉照片、林伟坠楼证据和异常音源线索在终章通过投影统一回收。
- 前序选择通过理智、体力、线索、团队信任、白秋羁绊、道具和少量关键标记影响终局，不需要给每个普通调查动作单独增加分支。

## 4. 三块空间

### A. 门厅/票务台

玩家出生位置。只需：

- 小型票务台或柜台；
- 一扇进入主厅的门；
- 一张褪色小剧场海报；
- 柜台上的旧胶片盒；
- 身后的入口门。

票务台不需要复杂售票机或大量票根。胶片盒可以使用简单圆盒模型，标签写着 `1953 / 苏婉`。

### B. 观众席与舞台主厅

这是最大空间，也是最终演出的场地。只需：

- 若干排简化座椅；
- 左右或中央一条可跑动通道；
- 舞台平台；
- 可开合或显隐的幕布；
- 舞台侧边一台老式放映机；
- 舞台中央一把旧木椅；
- 一块可显示图片的幕布/后墙。

第一次进入时，舞台为空、幕布关闭、放映机不工作。追逐后返回时，幕布打开、木椅和人物出现、放映机自动运转。复杂变化由灯光、雾、图片和人物显隐完成，不增加大量模型。

### C. 后台密室

后台、化妆区和一段返回主厅的短通道合并为一个密室。只需：

- 一张化妆桌和一面镜子；
- 一个道具柜/木箱；
- 一个简单配电箱；
- 一台可插入胶片盒的小放映设备，或与墙面投影相连的播放器；
- 一根红色总闸/开门拉杆；
- 返回主厅的门和短通道；
- 一组戏服架或人形轮廓，用于突然出现/消失的软惊吓。

密室不再包含音控室、独立配电间、侧门、舞台下层、多个证据房和多组座位机关。

## 5. 模型与道具预算

### 5.1 必须模型

| 类别 | 内容 |
|---|---|
| 建筑主体 | 门厅、主厅、后台密室三块空间及四扇左右的必要门 |
| 主厅 | 简化座椅排、舞台、幕布、投影面、旧木椅 |
| 密室 | 化妆桌镜子、道具柜、配电箱、放映机/播放器、总闸、戏服架 |
| 道具 | 旧胶片盒、备用保险丝 |
| 人物 | 白秋、陈九或陈九黑影、追逐用绳傀/长影；可先用现有角色占位 |

### 5.2 不制作

- 每个座位的红绳和独立交互；
- 坐满观众席的 3D 人群；
- 大量票据、录音带、账本、剪线钳、保险柜等细碎道具；
- 舞台机械吊杆、复杂机关、可完整行走的舞台下层；
- 多条追逐支路和大量藏身柜；
- 为每个结局制作完全不同的 3D 场景。

无脸观众、受害者姓名、旧医学院、林伟坠楼和苏婉往事都放进投影图片，不转化成实体模型。

## 6. 四个主剧情点

### T-P01「最后一盒胶片」——门厅

玩家进入门厅，身后的门自动关上，但此时不立即追逐。票务台上只有一个旧胶片盒，标签写着：

```text
1953 年五月
演出者：苏婉
最后一场
```

胶片盒旁边压着半张新纸条：“请把它带到后台。她等了很久。”纸条看似是苏婉留下的，实际字迹与陈九伪造记录相同。

玩家拾取胶片盒。它是本关唯一必须从开场带走的剧情道具：

- 在后台放映机中揭示真相；
- 最终带回舞台播放完整“最后一幕”；
- 若玩家此前线索高，可以发现盒中混入了现代剪接段；
- 若拥有苏婉照片，照片背面的字会在胶片盒附近显现。

剧情结束后，进入主厅的门打开。

### 主厅第一次经过——不设长剧情点

玩家经过空观众席。舞台幕布关闭，只有幕布后偶尔闪过人影。座椅不放红绳，也不坐 3D 观众。

软惊吓：

- 灯闪的一瞬，投影幕上出现一张“坐满观众的旧剧场照片”；灯恢复后仍是空厅。
- 玩家回头时，最后一排似乎坐着一个白衣轮廓；再次照去后消失。
- 舞台木地板传来拖椅声，但舞台上还没有椅子。

后台门在玩家靠近时自行打开。玩家进入后，门在身后重重关闭，正式进入密室逃脱。

### T-P02「镜子里站着谁」——后台密室第一剧情点

进入后台后返回门无法打开，化妆灯全部熄灭。玩家需要先进行一个很轻的找物机关：

1. 搜索道具柜/木箱；
2. 找到备用保险丝；
3. 把保险丝装进配电箱；
4. 化妆镜周围的灯逐盏亮起。

镜子惊吓分三步：

1. 玩家第一次看镜子，只有自己的视角和身后的戏服架。
2. 灯闪后，镜子里多出一个白衣女人，现实中身后没有人。
3. 玩家再次看镜子，白衣女人突然贴近镜面；图片跳脸后她又退回远处，抬手指向放映机。

这个惊吓使用镜面图片/贴图和统一 `JumpscarePipeline`，不需要制作复杂镜像角色动画。

随后出现简短剧情文字：苏婉不是在把玩家引向自己，而是在指向那盒被人改过的胶片。镜面短暂浮出一句反写文字：“别听最后一轨。”

前序影响：

- 持有黑猫毛发：真实苏婉一侧出现结霜，玩家不会把她误判为追逐者；
- 持有护身符：跳脸时符纸发热但不消耗；
- 理智较低：镜子里会出现两个不同方向的白衣人，苏婉照片可纠正方向。

### T-P03「被剪过的唱段」——后台密室第二剧情点

玩家把门厅取得的旧胶片盒放入后台放映机。机器最初转不动，玩家按下刚恢复的电源后，墙面开始播放三段图片：

1. 1953 年，苏婉在小剧场后台准备演出；照片角落有人搬入医学院旧设备。
2. 苏婉发现有人利用她的唱段和病人记录进行仪式，试图阻止后被杀害。
3. 现代的陈九把她的声音重新剪接，在林伟坠楼当晚通过扩音器播放。

第三段播放到一半会突然插入图片惊吓：画面中的陈九本来背对镜头，下一帧却贴到镜头前，佩戴真正杜学民的工牌。图片闪过后，放映继续，出现苏婉伸手阻止林伟靠近窗口的画面。

玩家在这里做本关第一个重要选择：

- **保留完整放映与录音**：获得更完整的人为证据，终局更容易公开真相；追逐开始时陈九仍能利用最后一轨定位玩家。
- **立即切掉最后一轨**：追逐更安全，白秋更容易清醒；但公开证据少一段完整原始录音。

选择分别设置 `theaterRecordingPreserved` 或 `theaterCommandTrackCut`。

放映最后一帧是此刻的小剧场舞台：白秋坐在木椅上，陈九站在她身后。字幕只有一句：“戏已经开始了。”

放映结束后，密室总闸亮起红灯。玩家拉下总闸，返回主厅的门打开，同时密室中的戏服架倒下，后面出现绳傀/黑色长影，追逐开始。

### T-P04「最后一幕」——主厅最终剧情点

短追逐结束，玩家冲回观众席与舞台主厅。空间只通过以下变化表现“完全变了样”：

- 原本关闭的幕布已经打开；
- 舞台中央出现旧木椅，白秋被固定在椅上；束缚只需单根腕带/角色姿态或投影光表现，不制作多圈绳索模型；
- 陈九或陈九黑影站在舞台侧面；
- 舞台侧边老式放映机自动转动；
- 观众席依然没有 3D 人群，但投影和闪光中会反复出现坐满人的旧照片；
- 主入口门重新亮起，但暂时打不开。

玩家把旧胶片盒带到舞台放映机，触发最终图片演绎。演绎完成后进入最后剧情选择和结局解析。

## 7. 后台短追逐

追逐目标很简单：**从后台密室沿短通道逃回主厅**。

建议长度 30–50 秒，不设计岔路谜宫。路线只有一条，但通过关门、转角和灯灭制造压力：

```text
密室放映机
  → 化妆桌转角
  → 戏服架旁窄道
  → 返回门
  → 主厅侧幕
  → 观众席安全触发区
```

追逐者继续使用白沙已经建立的“绳傀/红光长影”概念，明确不是苏婉。可以是简单黑色角色、长影或贴图，不要求复杂模型。

状态影响：

- `theaterCommandTrackCut`：追逐者晚出现数秒，速度略低；
- 保留完整录音：追逐者更快，但玩家获得完整公开证据；
- 体力高：可直接跑回主厅；
- 体力低：允许玩家关闭一扇门拖延，不做数值必死；
- 护身符：被抓时抵消一次并烧毁；
- 黑猫毛发：在正确门框出现短暂白霜；
- 低理智：通道尽头会短暂出现假门，但只延误，不把玩家永久带错。

到达主厅后，追逐者停在侧幕后，不进入最终舞台演绎。

## 8. 老式放映机最终演绎

### 8.1 演出方式

最终演绎不再依赖大量 3D 动画。舞台灯熄灭，老式放映机启动，图片以略微抖动、划痕、烧片和换片声一张张出现。每张图片配 1–2 句必要文字，停留约 5–8 秒；玩家可按键继续，也可开启自动播放。

图片播放期间：

- 陈九偶尔打断字幕，试图把责任推给苏婉、林伟或白秋；
- 玩家已找到的证据会覆盖他的说法；
- 缺少的证据不会让画面消失，而是以模糊、缺帧或“无法确认”表现；
- 白秋随着真实记忆出现逐渐恢复清醒；
- 有 `baiqiuBond` 时会插入雨夜共伞图，没有羁绊时替换为白秋独自在雨中的图。

### 8.2 公共放映图片清单

后续统一生成图片。每次完整放映使用 9 张，实际制作 10 份公共素材，因为 R07A/R07B 根据羁绊状态二选一：

| 编号 | 画面 | 叙事功能 |
|---|---|---|
| R01 | 1953 年小剧场后台，苏婉对镜整理戏服 | 建立她是具体的人，不是无名女鬼 |
| R02 | 镜中苏婉身后出现搬运旧医学院设备的人影 | 把小剧场与医学院连接起来 |
| R03 | 苏婉在暗处发现录音设备和被绑的人，准备阻止 | 确认她是警告者 |
| R04 | 陈九戴着杜学民工牌，在现代设备前剪接旧唱段 | 揭露人工犯罪层 |
| R05 | 农医馆借阅终端、小票和林伟听见喊名声 | 回收第一关 |
| R06 | 林伟站在窗前，苏婉从后方伸手拉他，另一侧扩音器发出命令 | 明确死亡责任 |
| R07A | 白沙雨夜，张超与白秋共一把伞 | 仅羁绊线使用 |
| R07B | 白秋独自在雨里握着符纸 | 非羁绊线替代图 |
| R08 | 当前舞台，白秋被困但抬头看向玩家，陈九只剩侧面黑影 | 从回忆切回现在 |
| R09 | 空观众席上短暂浮出历代受害者姓名，最后留下林伟的位置 | 把鬼故事还原成受害者 |

R01–R03 可在后台密室先播放裁切版，最终演绎再播放完整版本，不需要为两个阶段生成两套完全不同的图片。

### 8.3 镜子惊吓图片

建议额外生成 2 张：

- `theater-mirror-distant.png`：正常化妆镜中，玩家身后远处站着白衣苏婉；
- `theater-mirror-close.png`：同一机位，苏婉突然贴近镜面并抬手指向放映机。

这两张只承担镜面显示和跳脸，不需要把苏婉角色放进真实 3D 空间。

### 8.4 结局图片

不为每个结局建立新场景，只追加 1–2 张结局图：

- 共赴晨光：剧场门打开，启真湖晨光照入；张超与白秋并肩但不必拥抱。
- 雨停以后：天亮后的湖边，两人共用的伞已经收起，白秋主动握住张超的手；远处小剧场不再亮灯。
- 拨云见日：证据被保存、陈九被带走、苏婉照片写回姓名。
- 血色兄弟：空舞台上的两瓶酒与张一诚留下的门禁卡，避免直接血腥表现。
- 远走高飞：夜班车窗与被烧掉一半的 23:47 剧票。
- 最后一位观众：投影中所有观众同时转向镜头，现实观众席仍为空。
- 无尽噩梦：医院房门外出现小剧场放映机，医生胸前是杜学民工牌。

所有图片放在 `public/images/theater/` 或 `public/images/endings/`，运行时必须通过 `assetUrl()` 加载。

## 9. 最终演绎后的剧情选择

放映结束后，陈九继续播放最后一轨，白秋开始失去清醒。玩家选择行动，而不是直接选择结局名称：

1. **“让白秋自己完成最后一幕，我和她一起拉下总闸。”**
2. **“让胶片继续播放，把完整证据发送出去，等待张一诚和调查者。”**
3. **“关掉所有声音，带白秋从已经解锁的入口离开。”**
4. **“不再等待，直接冲上舞台制伏陈九。”**

白秋清醒后会主动松开第一道束缚，并告诉张超：“不要替我选。”最佳路线的核心动作是两人共同拉下总闸，不需要制作复杂断绳、灵魂锚或舞台机械动画。

最终选择“共同拉闸”时设置 `baiqiuAgencyRespected=true`。它只表示玩家尊重白秋自己作出决定，不能靠最后一次选择凭空补足此前缺失的好感度。

## 10. 结局组合门槛

为避免结局只检查一个数值或一件道具，先把前序状态归纳为四组可复用门槛。

### 10.1 三类证据

每类证据必须同时包含至少两项具体内容，不能只靠 `clues` 数值代替：

| 证据组 | 完整条件 | 作用 |
|---|---|---|
| **受害时间线** | 借阅小票 + 林伟笔记/日记残页之一 | 证明喊名、23:47 和历代案件存在连续关系 |
| **人为犯罪** | 后台完整录音 + 门禁卡日志/坠楼现场证据之一 | 证明陈九剪接音轨、进出后台并布置现场 |
| **苏婉保护** | 苏婉老照片 + 面对苏婉/黑猫毛发之一 | 证明她在警告和救人，而不是凶手 |

以 `theaterEvidenceGroupCount` 表示完成的证据组数量，范围 0–3。`clues` 决定玩家能否把已有证据组织成有效陈述，具体道具和标记决定证据是否真实存在。

### 10.2 白秋清醒

白秋可以通过三种方式恢复清醒，避免只有恋爱路线能救她：

1. **关系唤醒**：`baiqiuBond` 且好感度 ≥30；
2. **真相唤醒**：苏婉保护证据完整、团队信任 ≥60；
3. **保护唤醒**：护身符仍在且好感度 ≥20，或护身符已消耗但老照片与日记同时在手。

满足任一方式后设置 `baiqiuAwake=true`。高好感度用于打开感情结局，不垄断基本救援结果。

### 10.3 团队支援

`teamReady` 需要：

- 团队信任 ≥60；
- `yichengTrustsYou=true`；
- 玩家选择保留并发送完整录音，或此前已向调查者发送启真湖拼证结果。

只有高信任但没有具体约定，张一诚仍可能因愧疚提前冲台；只有标记但信任过低，他也不会确信玩家发出的信号是真的。

### 10.4 追逐与撤离准备

`escapeReady` 满足任一项即可：

- 体力 ≥25；
- 能量饮料仍在或白沙已取得持续加速标记；
- 护身符仍在，可抵消一次抓捕；
- 已切掉最后一轨，使绳傀延迟出现。

低体力不会直接判死，但没有任何补给、保护或音轨准备时，选择撤离会失败。

## 11. 结局路由

| 结局 | 核心条件 | 结果 |
|---|---|---|
| **雨停以后** | 在“共赴晨光”条件上，额外要求 `baiqiuBond`、好感度 ≥45、`baiqiuAgencyRespected`，且 `baiqiuReassured`/`askedHowToHelpBaiqiu` 至少一个成立 | 仪式结束后白秋主动回应两人的感情。她没有被爱情“治好”，而是在专业支持和自己的选择下继续生活；毕业后两人仍一起走过那条雨夜路线。这是高好感度感情结局，优先于“共赴晨光”结算 |
| **共赴晨光** | 选择共同拉闸；`baiqiuAwake`；理智 >20；苏婉照片；切掉最后一轨；至少两类证据完整 | 白秋主动完成最后一幕，张超与她共同关闭总闸；苏婉唱完未被剪接的最后一句，陈九失去控制，23:47 循环结束。无需恋爱关系也能达成 |
| **拨云见日** | 选择继续放映并上传；完整录音已保留；线索 ≥70；三类证据全部完整；`teamReady` | 张一诚和调查者按信号进入，陈九被控制，证据公开，苏婉恢复姓名；爱情线不是必要条件 |
| **远走高飞** | 选择离开；`baiqiuAwake`；`escapeReady` | 两人活着离开，但若没有完整录音和至少两类证据，案件与小剧场根源不会被处理；多年后仍收到 23:47 剧票 |
| **血色兄弟** | `yichengTrustsYou=true`，但因未发送可靠信号/证据不足而没有形成 `teamReady`；玩家直接冲台或冲突失控，且最后一轨未切断或玩家体力 <25 | 张一诚因信任玩家而赶来，却没能按安全计划进入，最终为阻止陈九冲上舞台并牺牲；陈九被制服，白秋获救。可靠信号、门禁日志、完整录音和切轨准备共同决定能否避免他的死亡 |
| **最后一位观众** | 白秋没有清醒便强行拉闸/撤离；追逐失败且没有护身符；公开或强攻失败时也没有 `teamReady` | 陈九完成转移，张超或白秋成为下一位“演出者”；投影观众同时转向镜头 |
| **无尽噩梦** | 理智 ≤20 且现实锚不足两项 | 张超在医院醒来，被告知小剧场从未开放；门外医生佩戴真正杜学民的工牌并对镜头眨眼 |

现实锚仍采用：苏婉照片、日记、启真湖拼证、`baiqiuBond`、林伟现场证据。低理智但现实锚充足的玩家可以继续，只会遭遇更多假镜像和错误字幕。

### 11.1 结算优先级

1. 理智 ≤20 且现实锚不足两项：无尽噩梦。
2. 追逐失败且没有护身符，或白秋未清醒便强行行动：最后一位观众。
3. 满足高好感度条件并选择共同拉闸：雨停以后。
4. 满足普通共同拉闸条件：共赴晨光。
5. 满足完整公开条件：拨云见日。
6. 成功撤离：远走高飞。
7. 张一诚介入但准备不足：血色兄弟。
8. 其余失败情况：最后一位观众。

`阴阳两界`仍按总案作为好结局后的隐藏尾声判断，不占上述七种主结局名额。

### 11.2「雨停以后」感情演出

该结局沿用“共赴晨光”已经解决仪式的结果，再追加约 40–60 秒感情尾声：

1. 放映机烧掉最后一帧，共伞图片 R07A 从雨夜慢慢过曝成清晨。
2. 白秋走出剧场后主动握住张超的手，把那把旧伞合起来，说：“那天我说，紫金港的承诺是要还的。以后下雨，换我陪你走。”
3. 数月后的短图显示两人继续各自的学习和生活。白秋接受合适的专业支持，也保留自己解释经历、决定关系和规划未来的权利。
4. 最后一张图中，两人经过白沙楼下同一盏路灯。没有歌声、没有任务提示，白秋先向前走，又回身等张超跟上。

结尾文字建议：

> 后来他们仍会害怕，也仍会争吵。只是从那个清晨开始，谁都不再用“为你好”替另一个人作决定。雨再落下来时，他们知道该去哪里找对方。

按现行前序数值，好感度 45 接近终章前可达到的高位，需要玩家持续选择陪伴、共伞、报平安或询问如何帮助白秋，不能靠最后一个选项临时刷出。

## 12. 前序状态如何回流

| 前序状态 | 终章影响 |
|---|---|
| 理智 | 决定镜中假影、投影错帧和无尽噩梦风险 |
| 体力 | 决定短追逐和离开路线容错 |
| 线索 | 决定放映字幕有多少内容能被玩家证实、公开路线是否成功 |
| 团队信任 | 决定张一诚是否等待信号、是否安全进入而不是擅自冲台 |
| 白秋羁绊/好感度 | 决定是否出现共伞图、能否用私人记忆快速唤醒白秋；好感度 ≥45 并满足持续关心标记才进入“雨停以后” |
| 手电筒 | 更快找到保险丝和返回门，减少密室搜索造成的理智损失；不作为结局硬门槛 |
| 借阅小票/林伟笔记 | 证明 23:47 喊名记录不是苏婉原始唱段 |
| 日记残页 | 证明同类事件跨越多年，不只是林伟单案 |
| 门禁卡 | 作为陈九进出医学院和剧场后台的日志证据；不再用于开启额外配电房 |
| 苏婉照片 | 让后台胶片恢复缺失画面，识别她是警告者 |
| 黑猫毛发 | 区分镜中的真实苏婉与低理智假影 |
| 护身符 | 提供一次追逐/控制容错，保留到最后可帮助白秋稳定 |
| 镇定药 | 在最终放映前恢复理智，可能让玩家跨过“无尽噩梦”和共同拉闸的理智门槛 |
| 能量饮料/白沙加速标记 | 构成 `escapeReady`，帮助低体力玩家完成追逐或撤离 |
| 之前相信张一诚 | 他按口令支援，降低“血色兄弟”风险 |
| 之前面对苏婉 | 最终放映能显示她伸手救林伟的完整一帧 |
| 在论坛给白秋报平安 | 设置 `baiqiuReassured`，证明感情不是终局前才突然出现 |
| 向调查者询问如何帮助白秋 | 设置 `askedHowToHelpBaiqiu`，证明玩家关注她的选择与长期生活，而不只是救出人质 |

## 14. 程序与模型对接

小剧场仍可复用 `Interior3D` 的移动、碰撞、手电、HUD、统一跳脸和剧情弹层；增加一个简化 `TheaterExperience` 控制阶段显隐、镜面图片、放映图片、关门和短追逐。

前文两个现有选择需要补持久标记：`message-baiqiu` 设置 `baiqiuReassured`，`ask-baiqiu` 设置 `askedHowToHelpBaiqiu`。最终选择共同拉闸时设置 `baiqiuAgencyRespected`。这三个标记只用于证明感情线有持续行为支撑，不额外增加剧情点。

## 15. 检查点与验收

检查点：

1. 门厅拾取胶片后；
2. 安装保险丝后；
3. 追逐开始前；
4. 返回主厅、最终放映前。

必须验证：

- 不需要细小座椅道具或 3D 人群也能成立；
- 胶片盒与保险丝都清晰可见，不会因遗漏永久卡关；
- 镜面惊吓只在镜中出现，回头后现实空间没有苏婉；
- 后台只有两段主剧情，机关操作不会额外弹长文本；
- 追逐路线单一、短且可以在低体力下通过关门容错完成；
- 返回主厅后只靠幕布、灯光、人物、椅子和投影变化形成明显反差；
- R07A/R07B 根据羁绊状态互斥播放；
- 保留录音与切断最后一轨形成明确取舍；
- 高羁绊低线索不能凭感情公开完整案件；高线索低羁绊仍可获得“拨云见日”；
- 好感度达到阈值但没有持续关心标记，不能只靠终局一次选择进入“雨停以后”；
- 护身符、能量饮料、门禁卡、日记、照片和黑猫毛发都至少影响一项终章玩法或结局门槛；
- 低理智但现实锚充足时仍能通关；
- 所有图片经 `assetUrl()` 加载，生产环境同步 R2。

## 16. 当前锁定内容

- 三块空间，不继续扩房间。
- 四个主剧情点，密室内正好两个。
- 两个新实体道具：旧胶片盒、备用保险丝。
- 一个简单找物/通电机关、一台放映机、一个最终总闸。
- 镜子图片惊吓、胶片图片惊吓、戏服架出现/消失等软惊吓。
- 一段 30–50 秒的后台到主厅短追逐。
- 返回主厅后用同一场景换灯光、幕布和人物显隐。
- 最终演绎以公共投影图片为主，结局追加少量图片。
- 七种结局，其中“雨停以后”为高好感度感情结局。
- 结局由五项属性、三类证据、前序道具、关键选择和终章两次选择共同解析。
