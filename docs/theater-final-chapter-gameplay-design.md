# 终章：小剧场具体玩法与多结局实施策划

> 状态：基于 `public/models/interiors/theater/theater.glb` 的首轮可玩规格。
> 本轮范围：剧情与关卡策划，不实现代码、不修改模型、不生成正式图片。
> 空间范围：门厅 / 票务台、观众席与舞台主厅、后台密室三块，不扩建新房间。
> 主剧情量：4 个主剧情点，其中后台恰好 2 个；门厅 T-P01 内部允许多页剧情链。
> 主题：陈九把受害者写进了一出鬼戏；玩家最后要做的，是让他们重新拥有姓名与选择。

## 1. 模型实测结论

### 1.1 文件与结构

- 运行时模型：`public/models/interiors/theater/theater.glb`
- 文件大小：88,876,068 bytes，约 88.9 MB。
- Blender 5.1.2 实测导入结果：22,543 个对象，其中 7,265 个网格。
- Blender 世界边界：X `7.7195–32.8496`，Y `-5.8458–23.4603`，Z `-0.15–7.25`。
- 模型大部分节点沿用 SketchUp / 素材库的 `Node_####`、`Geom3D.####` 名称，不能把玩法逻辑直接绑定在这些数字节点上。

结构可以稳定辨认成三块：

1. 主厅与舞台主要落在 X `7.9–22.9`、Y `-5.8–13.9`。
2. 后台家具主要落在 X `23.1–30.9`、Y `-4.2–11.9`，与主厅右侧相邻。
3. 门厅 / 后排入口主要延伸到 Y `13.9–23.5`，地坪高于舞台前部，模型内已经用阶梯解决落差。

模型实测到的可复用家具：

|---|---|---|
| 大型监控控制台 | `CGM Operator desk R6`；约 X `23.12–24.84`、Y `2.27–6.71` | 后台开灯机关与第二剧情点共用，不新增第二台设备 |

### 1.3 指定复用资产

- 胶片源模型已经存在：`3D_Assets/JDH5455681510_fbx/3d66.com_JDH5455681510.fbx`，大小约 12.1 MB。正式接入时单独清理、归一比例并导出为轻量 GLB，不把整个 FBX 直接塞进主场景。
- 追逐鬼复用第三关地下车库道具包 `medical-garage-props.glb` 中的语义根 `medical_garage_ghost`。不重新建鬼模型。
- 梳妆台上的可查看相框复用白沙宿舍相框，不使用模型墙上六个小相框逐一交互。
- 舞台苏婉、镜面三图与最终演绎都用图片完成，不要求制作苏婉骨骼动画。

## 2. 关卡节奏

建议首次游玩 16–23 分钟：

```text
门厅暴雨、拾取胶片与长剧情链       4–6 分钟
第一次进入主厅、苏婉闪现           20–40 秒
后台锁门、开灯、相框三图           3–5 分钟
控制台“被剪过的唱段”剧情链         4–6 分钟
后台短追逐                         15–30 秒
观众席触发、舞台最终演绎与选择      4–6 分钟
结局与统一尾声                     2–4 分钟
```

全关只新增一个必须拾取的实体道具“苏婉旧胶片”。没有保险丝找物，没有多房间钥匙链。可玩性来自状态变化、观察、文字判断、图片惊吓、短追逐和终局决策。

## 4. T-P01 门厅：最后一盒胶片

### 4.1 出生与天气

玩家出生在门厅外侧入口。身后的玻璃外持续暴雨，雨水不进入室内：

- 室外雨幕使用一层远景粒子和玻璃流痕贴图，不逐滴模拟。
- 雷声间隔 7–15 秒随机；闪电发生时，玻璃外冷白光先亮 80–140 ms，室内再有一次较弱反射。
- 第一次雷击固定发生在出生后 1.5 秒，用来照出票务台上的胶片轮廓。
- 门厅主灯昏黄且稳定，不在开场连续频闪，给玩家一个安全假象。
- 小地图只显示票务台红点；主厅门此时不可交互。

胶片盒标签：

```text
R-1953
苏婉
五月九日 / 最后一场
```

盒盖边缘有老旧封蜡，也有一小段明显属于现代的透明胶带。仅这一处视觉信息就先告诉玩家：这不是一件从 1953 年原封不动保存到现在的遗物，有人近年打开并重新封过。

拾取后获得新道具 `film_reel`，立即保存检查点 `theater_reel_collected`，开始同一个物理点内的三页剧情链。

### 4.2 剧情页 A：谁动过胶片

正文建议：

> 铁盒比看起来更沉。盒盖上的“苏婉”已经被水汽蚀得发白，只有 R-1953 的编号仍像刚写上去。你沿着封蜡摸到一圈断口，又摸到后来贴上的透明胶带。有人打开过它，而且就在不久以前。
> 盒里没有放映机转动的声音，只有几厘米松脱的胶片在金属壁上轻轻刮擦。闪电透过玻璃，胶片最外侧一帧短暂透亮：一个穿戏服的女人背对镜头，手却指向舞台以外。
> 票务台抽屉里压着半张新纸：“请把最后一场送回后台。她等了很久。”这句话在劝你把胶片带进去；而你一路找到的证据，都在提醒你不要照着陌生人的指令行动。

第一轮选择：

| 选择 | 条件与反馈 | 持久影响 |
|---|---|---|
| 用借阅小票比对编号与时间 | 有 `receipt` 时可选；发现小票的异常归还编号正是 R-1953，且两者都有 23:47 压痕 | `foyerReelMatchedReceipt=true`；线索 +6；受害时间线证据加强 |
| 把苏婉老照片贴在胶片外侧 | 有 `photograph` 时可选；两处“苏婉”字迹相同，纸条字迹却不同 | `foyerReelMatchedPhoto=true`；线索 +5；苏婉保护证据加强 |
| 直接掀开盒盖查看首段 | 永远可选；看到旧画面中插入了颜色、齿孔都不同的现代胶片 | `foyerSawModernSplice=true`；理智 -3、线索 +4；后续字幕更早显示“人为剪接” |

三个选项都能继续，不因玩家缺少前序道具卡关。

### 4.3 剧情页 B：把真相交给谁

一声雷后，手机恢复一格信号。胶片盒内侧刻着一行很浅的反字：

> 我唱的是“离开窗边”。他们留下的，只剩“到窗边来”。

这句话揭示部分真相：苏婉唱段的语序被重新剪过，但此处还不揭露陈九完整目的，也不直接说明白秋在舞台上的处境。

第二轮选择：

| 选择 | 即时表现 | 持久影响 |
|---|---|---|
| 拍下盒内反字与现代接缝，发给张一诚和调查者 | 消息显示“已发送”，但对方暂不回复 | `theaterEvidenceBackedUp=true`；团队信任 +6；是安全支援条件之一 |
| 给白秋发消息：“等我见到你，我会先听你说，不替你决定。” | 消息一直显示未读；玻璃反光中的人影轻轻点头 | `theaterPromisedAgency=true`；好感度 +8、理智 +2；感情结局连续行为证据 |
| 关闭手机，先用已有证物确认自己没有听错 | 有照片 / 日记 / 羽毛任一项时反馈更完整 | `theaterPreparedRealityAnchor=true`；理智 +5；降低低理智假字幕强度 |

### 4.4 剧情页 C：最后一轨

胶片最外层自行松出一小段。旧画面之间夹着三格现代字幕：

```text
第一轨：伴奏
第二轨：原唱
第三轨：姓名
```

播放器并不在门厅，玩家无法在这里处理它，只能先作出判断：

| 选择 | 影响 |
|---|---|
| “苏婉留下的是警告，她在把我引离那条声音。” | `trustedSuwanBeforeHall=true`；主厅鬼影只扣少量理智；最终苏婉证词更清晰 |
| “有人借她的脸引我进去，我只相信可验证的证据。” | `reservedJudgment=true`；线索 +3；控制台优先显示编辑记录 |
| “先不判断。记住原句：离开窗边。” | `memorizedOriginalWarning=true`；理智 +2；终局可用原句唤醒白秋 |

选择结束，主厅门锁“咔哒”弹开。票务台红点消失，剧情链算作一个主剧情点 T-P01。

## 5. 第一次进入主厅：舞台闪过苏婉

玩家越过 `mainHallThreshold` 的瞬间触发一次不可重复的视觉惊吓，不弹文字框，不夺走长时间控制权：

| 时间 | 表现 |
|---:|---|
| 0 ms | 主厅环境声突然抽空，只剩鞋底声 |
| 80 ms | 一次近距离雷声，玻璃方向冷白闪电 |
| 120 ms | 舞台中心闪出穿旧戏服的苏婉图片，身体略侧，脸朝玩家，右手指向后台 |
| 520 ms | 图片随闪电熄灭，不留下实体或红点 |
| 800 ms | 环境声恢复，后台镜子开始发暗红光，小地图红点落在镜子位置 |

图片暂定：`public/images/theater/theater-stage-suwan-flash.png`。画面应是戏服苏婉，不使用追逐鬼模型；她的姿态是急迫警告而非扑向玩家。若 `trustedSuwanBeforeHall=true`，理智 -1；否则理智 -3。这里不调用完整跳脸管线，把强惊吓留给镜面第三图。

舞台此时不播放最终影像，也不要求玩家搜索观众席。唯一明确目标是后台镜子的红点。

## 6. 后台入场与封门

### 6.1 门的三态

后台门采用独立的轻量门板与碰撞体，不尝试控制 GLB 中难以稳定定位的数字节点：

1. `ABSENT`：玩家从主厅接近时，门板与碰撞都不存在，入口是开的。
2. `SEALED`：玩家整个身体越过后台触发线 0.45 米后，门板在其身后瞬间出现，碰撞启用，重关门声播放。
3. `OPEN_FOR_CHASE`：追逐开始时门板和碰撞一起消失，成为逃回主厅的出口。

封门后不允许通过反复贴门提前触发开门；只有完成镜面三图和“被剪过的唱段”剧情链，追逐开始时才解除。

### 6.2 全黑与目标转移

玩家进后台前，镜子以很弱的红色自发光吸引玩家。门出现后：

- 后台所有顶灯立即熄灭。
- 镜子红光也完全熄灭。
- 鬼从玩家进后台那一刻起就在 `ghostDormant`，但材质透明度约 0.10–0.14、无红灯、无小地图标记；正常路线很难注意到，刻意用手电扫戏服架三时可以看到一次不确定轮廓。
- 控制台的一个实体开关亮起微弱红光，小地图红点从镜子切换到控制台。
- 手电可以正常使用。即使玩家没有手电，控制台红光也保证不会软锁。

## 7. T-P02 后台第一剧情点：镜子与相框

### 7.1 控制台开灯

玩家在监控控制台按下红色开关，这是一次单键互动，不需要找保险丝：

1. 开关红光熄灭。
2. 梳妆镜周围灯泡按“左一、右一、左二、右二”的顺序逐盏亮起，建议 10 盏灯、总时长 2.5 秒。
3. 第七盏亮起时，戏服架三后方出现一次很轻的布料摩擦声；不移动鬼，不弹惊吓。
4. 所有镜灯亮起后保持暖白色，天花板顶灯始终不亮。
5. 小地图红点回到镜子；梳妆台上的白沙相框模型从不可交互变为可交互。

这样把“找到电源”的探索压缩到一个清楚目标，把注意力放在镜面构图和随后剧情，而不是低价值找小道具。

### 7.2 三张相框图片

玩家走到镜前查看相框。相框图片沿用白沙宿舍的查看方式：图片覆盖主要视野，不增加卡片边框；每张正常停留 3 秒，3 秒后自动进入下一张，也允许点击任意位置或按任意键提前进入下一张。

为保证惊吓节奏：每张图片显示后的前 350 ms 禁止跳过；第三张前 1 秒完全锁定跳过，1 秒后必定进入游戏内跳脸。

| 图片 | 构图与注意力设计 | 播放规则 |
|---|---|---|
| M01 正常镜面 | 第一人称站在梳妆镜前；镜中只有玩家视角、暖白镜灯和身后的戏服架，空间与真实后台一致 | 3 秒；建立“正确画面”基线 |
| M02 视觉诱饵 | 完全相同机位；镜中戏服架前多出穿戏服的苏婉，她的脸和反射成为中央高对比焦点，现实画面边缘仍看似正常 | 3 秒；玩家注意力被牢牢吸到镜中主目标 |
| M03 次级面孔 | 保留 M02 的中央苏婉，不突然换构图；画面最右侧、玩家肩后或镜框外黑区多出一张离镜头很近的扭曲面孔。它不在第一视觉落点，利用玩家仍注视中央人物时产生“后知后觉”惊吓 | 显示 1 秒后强制触发游戏跳脸；不允许在 1 秒前跳过 |

第三图的扭曲面孔属于陈九操纵的追逐鬼，不是苏婉。游戏跳脸复用统一 `JumpscarePipeline`，图片可使用镜中面孔的更近裁切；跳脸结束后关闭图片查看，恢复玩家控制。

道具与指标影响只改变反馈，不改变必经流程：

- 有 `photograph`：M02 的苏婉服饰与老照片一致，跳脸后得到“她指向的是控制台，不是你”的确认。
- 有 `owl_feather`：M03 的中央苏婉保持清晰，右侧怪脸出现压缩错位，强调只有后者是被篡改层。
- 护身符仍在：游戏跳脸造成的大额理智伤害由现有护符机制抵消并烧毁；流程继续。
- 低理智：M01 镜中玩家动作会晚半拍，但三图顺序和出口方向不变，不用假目标把玩家永久带错。

跳脸后，镜面短暂出现反字：

> 被剪掉的不是一句唱词，是“不要”。

控制台屏幕随后自行亮起，小地图红点切回控制台，进入第二个后台剧情点。

## 8. T-P03 后台第二剧情点：被剪过的唱段

本段不播放录音，不要求制作语音。控制台以“字幕转写、编辑记录和门禁时间”三层文字揭露真相。设备 UI 可以有监控台边框，正文与选择仍复用统一剧情排版。

### 8.1 公共正文

> 控制台六块屏幕只有中间一块亮着。它没有声音，只显示两列自动转写。左列标着“R-1953 原唱”，右列标着“23:47 现场输出”。
> 左列断断续续：不要应声。不要回头。离开窗边。不要把名字交给他们。
> 右列却变成：应声。回头。到窗边来。林伟。白秋。张超。
> 两列用的是同一段声音。右列没有新增完整句子，只把“不要”剪掉，把三个后来出生的名字塞进停顿，再把警告重新排成命令。苏婉的歌没有把人带向窗边；有人用她的声音，把退路剪没了。
> 屏幕底部还有一条没有关闭的编辑会话。登录名是“杜学民”，时间却在真正的杜学民死亡之后。会话创建者没有退出，因为他还在等最后一个名字走上舞台。

此处明确告诉玩家：苏婉原本警告、唱段被现代人剪接、林伟的死亡受到人为诱导。仍暂不把陈九全部仪式独白一次说完，张超为何被选、白秋为何能反抗留给最终演绎。

### 8.2 第一轮选择：先固定哪一层证据

控制台会在 25 秒后自动清除缓存。玩家只能优先完整复制一层，其余层保留摘要：

| 选择 | 具体结果 | 后续作用 |
|---|---|---|
| 复制“R-1953 原唱字幕” | 得到完整警告顺序；有老照片时显示苏婉亲笔校对符号 | `theaterOriginalLyricCopied=true`；加强苏婉保护证据；终局真相唤醒白秋 |
| 复制“剪接记录与登录时间” | 有门禁卡时自动比对出陈九使用死亡后的杜学民身份 | `theaterEditLogCopied=true`；加强人为犯罪证据；公开真相路线关键 |
| 复制“三名目标与舞台调度” | 看到林伟标记“启动”、白秋标记“中介”、张超标记“容器” | `theaterTargetListCopied=true`；直接提高救援判断；白秋更易清醒，但公开罪证较弱 |

`clues ≥ 70` 或启真湖拼证完整时，未优先复制的两层各额外保留一条摘要；线索不足时只保留标题。这样线索数影响信息完整度，但不取消选择。

### 8.3 第二轮选择：如何处理最后一轨

屏幕提示“第三轨：姓名 / 已接入舞台与后台”。玩家必须选一种处理方式：

| 选择 | 旗标 | 代价与收益 |
|---|---|---|
| 删除姓名轨并切断后台输出 | `theaterCommandTrackCut=true` | 追逐鬼晚 1.2 秒恢复实体、最高速度较低；白秋更易脱离喊名控制；完整原始编辑包不再存在，公开路线证据要求更高 |
| 保留编辑包并立即上传 | `theaterTrackPreserved=true`、`theaterEvidenceBackedUp=true` | 团队可取得最完整证据；轨道仍在现场输出，追逐立即开始且鬼正常速度；是“拨云见日”的关键条件 |
| 用羽毛固定缓存，把姓名轨隔离但不删除 | 需要 `owl_feather`；`theaterTrackIsolated=true` | 追逐速度居中，保留编辑日志但没有完整可复现音轨；共同拉闸与公开路线都可用，但分别还需其他条件 |

选择确认后，最后一行文字覆盖屏幕：

> 后台监控 03：检测到第四个人形。位置——戏服架后。

玩家读完这行并关闭剧情框，短追逐立刻开始。

## 9. 后台短追逐

### 9.1 出场

- 鬼此前一直位于玩家标注的蓝色三角处，即戏服架三外侧阴影。
- 剧情框关闭 300 ms 后，戏服架晃动，鬼从架后横移半步再朝玩家转身。
- 材质在 0.6 秒内由透明度约 0.12 恢复到 1；地下车库的幽灵红光恢复，但强度比第三关低，避免整个后台被照亮。
- 同一时刻，堵住后台入口的门板与碰撞在 150 ms 内消失，小地图红点移到主厅出口。
- 不再要求玩家拉闸、开锁或捡取任何东西。

### 9.2 路线

沿用户蓝线锁定一条可读的环形路线：

```text
监控控制台
  → 绕过中部戏服架左侧
  → 贴后台南侧经过梳妆区外缘
  → 穿过木箱与东侧黑区之间的宽缝
  → 绕过鬼最初所在的戏服架外侧
  → 沿东 / 北侧回到后台出口
  → 冲入主厅
```

这不是迷宫，不设置岔路假门。木箱和三组戏服架负责遮挡视线与迫使转弯，路线地面不画发光引导线；出口红点、门消失和主厅透入的微弱冷光已经足够指路。

### 9.3 速度与抓捕

- 目标时长 15–30 秒。
- 玩家沿用室内步行 / 奔跑速度；鬼建议基础速度 2.2–2.4 m/s、最高 2.7–2.9 m/s，低于玩家正常冲刺速度。
- `theaterCommandTrackCut`：鬼延迟 1.2 秒，最高速度 2.6 m/s。
- `theaterTrackPreserved`：无延迟，最高速度 2.9 m/s。
- `theaterTrackIsolated`：延迟 0.5 秒，最高速度 2.75 m/s。
- 体力不足也不应必死；鬼的慢速保证玩家用步行加短冲刺仍能到达出口。

鬼碰到玩家时：

1. 触发 0.45–0.65 秒的游戏内贴脸与冲击声。
2. 不暂停移动输入、不传送玩家、不重置追逐、不判失败。
3. 第一次接触理智 -4；之后 2.5 秒内接触不重复扣除。
4. 鬼短暂停顿 0.8 秒并退后约 1.5 米，防止连续贴脸遮住路线。
5. 护身符可抵消第一次理智伤害，但不是逃生必需品。

玩家整个身体越过 `backstageEscape` 后：鬼停在门槛内，0.35 秒淡出并彻底隐藏，碰撞关闭，追逐完成。鬼绝不进入主厅，也不继续显示在小地图上。

## 10. T-P04 观众席与最终舞台演绎

### 10.1 到达观众席中央

玩家逃回主厅后不立刻弹剧情框：

- 小地图在观众席中央通道设置红点 `audienceCenter`。
- 玩家可以喘息并确认鬼没有追出；后台门保持消失状态。
- 进入半径约 1.4 米触发区后，锁定移动与视角，后续直到结局结束都不再要求玩家操作角色走动。

时序：

| 时间 | 表现 |
|---:|---|
| 0–250 ms | 画面快速压黑，所有环境声淡出 |
| 250–3000 ms | 全黑，只播放由慢到快的心跳；约第 1、2、2.7 秒各一次明显心跳 |
| 3000 ms | 舞台中央亮起暗红主光 |
| 3200–3900 ms | 左、右、后方三束红色聚光依次打开，全部指向舞台中央；观众席仍黑 |
| 4000 ms | 胶片转动声开始，第一张最终图片直接出现在舞台投影面 |

不需要制作每个座位的红绳、满场 3D 观众或复杂舞台机械。三至四盏聚光灯、一个图片面片和场景全黑即可形成终局仪式感。

### 10.2 最终放映规则

- 图片直接显示在舞台上，不弹全屏卡片。
- 每张默认停留 3 秒；显示 350 ms 后允许点击任意位置或按任意键提前下一张。
- 不提供倒退，避免打断终局节奏。
- 切换使用 100–150 ms 白闪、胶片划痕和极短换片声。
- 图片下方只出现 1 句必要文字，使用无边框字幕，不遮住核心人物。
- `film_reel` 是放映必要状态。由于它是开场必拾取物，正常流程不会缺失；检查点恢复时必须自动保留。

公共放映共 9 张，R07 根据羁绊二选一：

| 编号 | 画面 | 字幕 / 叙事作用 |
|---|---|---|
| R01 | 1953 年后台，苏婉对镜整理戏服 | “她有名字，也有一场没能唱完的戏。” |

| R04 | 现代的陈九戴着杜学民工牌剪接旧唱段 | “死人身份登录的那一晚，警告被剪成了命令。” |

持有证据会让相应图片更完整：

- 有照片且 `theaterOriginalLyricCopied` 时，R01–R03 无缺帧。
- 有门禁卡且 `theaterEditLogCopied` 时，R04 清楚显示死亡后的登录时间。
- 有林伟现场标记时，R06 多显示半秒苏婉把林伟向后拉的动作。
- 证据不足不删除公共真相，只把“可以向外界证明”的部分降级，避免终章信息不全到无法理解。

## 11. 最终两轮剧情选择

R09 播完后舞台图片熄灭。玩家保持站在观众席中央，先播放一段公共文字演绎，再进入两轮选择。

### 11.1 放映结束后的公共演绎

建议正文：

> 最后一张照片烧白以后，舞台并没有重新变黑。苏婉的影子还留在幕布上，嘴唇一开一合，却没有声音。陈九站在红光之外替她把话说完：“你们不是已经看见了吗？一段声音不需要说谎。只要剪掉几个字，人会自己走到该去的地方。”
> 他承认林伟并不是偶然听见歌声。林伟拿走 R-1953，想把被删掉的警告恢复出来。陈九便把他的名字塞进第三轨，让扩音器在每一个转角重复那两个字，直到他再也分不清警告来自哪里。
> 白秋抬起头。她说自己从小就能在梦里看见苏婉，却一直以为那是另一个正在夺走她生活的人。直到今晚她才看清：每当第三轨响起，苏婉都在用自己的影子挡住舞台后面那扇门。她从来不是在等献祭，她守在这里，是不让里面的东西出去。
> 陈九要白秋成为开门的中介，再把自己送进张超的身体。他故意把她的感知、恐惧和反抗都写成“发病”，因为只要所有人都不再相信她，她说出的警告就和苏婉被剪掉的“不要”一样，可以从故事里消失。
> 白秋看向你，没有说“救我”。她先问：“你到这里之前，有没有替我答应他任何事？”
> 若门厅选择过 `theaterPromisedAgency`，张超回答：“没有。我答应的是先听你说。”白秋闭了一下眼，再睁开时手指停止颤抖。若没有这项承诺，她只说：“那现在问我。别再让别人替我写完。”
> 观众席最后一排传来一声空椅折起的轻响。你想起林伟曾经也试图留下证据，想起苏婉的整段警告被剪成了相反的意思。今晚真正的最后一幕，不是谁牺牲自己去救另一个人，而是谁还能在恐惧里保留说“不”的权利。

这段演绎完成三个任务：把林伟、苏婉、白秋与张超四条线收束；明确陈九的具体手法和最终目的；把最佳行动的主题从“英雄救人”改成“恢复被剥夺的选择”。之后再让玩家决定先说什么、再做什么。

### 11.2 决策 A：先让谁从剧本里醒来

正文：

> 红光里，白秋的手还能动。陈九让她重复第三轨里的名字，每重复一次，舞台上的影子就离你更近一点。
> 苏婉没有扑向任何人。她站在投影烧焦的边缘，像在等你把那句被剪掉的“不要”还给她。
> 你只有一次先开口的机会。先说出的那句话，决定谁能在下一步保留自己的意志。

选择：

| 选择 | 条件 / 结果 |
|---|---|
| 喊白秋的名字，并复述雨夜里只有你们知道的约定 | 有 `baiqiuBond` 时效果完整；设置 `finalCalledBaiqiu=true`，关系唤醒权重最高。无羁绊仍可选择，但只能让她短暂抬头 |
| 举起老照片，把“不要应声、离开窗边”完整念给苏婉 | 有 `photograph` 或 `memorizedOriginalWarning` 时可完成；设置 `finalRestoredWarning=true`，真相唤醒与共同拉闸条件加强 |
| 先把编辑记录与目标名单发给张一诚和调查者 | 设置 `finalSentSignal=true`；有前序备份 / 编辑日志时形成安全支援，否则只是一次不完整求救 |

### 11.3 决策 B：谁来决定最后一幕

第一轮反馈结束后，进入最终行动。选项写行动，不写结局名称：

1. **“问白秋是否还能站起来；等她回答后，与她一起按下舞台总控的断开键。”**
   设置 `finalAction="together"`。只有白秋回答“我自己来”才设置 `baiqiuAgencyRespected=true`；玩家不能替未清醒的她强行作出共同决定。
2. **“让舞台继续放映，把完整编辑包公开，按约等待支援进入。”**
   设置 `finalAction="broadcast"`。需要证据、团队信任和安全信号共同支撑。
3. **“关掉离自己最近的扬声器，带白秋从主入口离开。”**
   设置 `finalAction="leave"`。能保命但未必终结循环。
4. **“不再等任何人，直接冲上舞台制伏陈九。”**
   设置 `finalAction="force"`。依赖体力和团队准备，风险最高。

两轮选择让门厅承诺、后台证据处理和最终行动形成连续因果；任何一个终局按钮都不能单独覆盖此前状态。

## 12. 指标、道具与前序选择回流

### 12.1 当前项目真实状态

现行代码已有五项指标：`sanity / stamina / clues / trust / affection`。现行道具为：

`talisman / flashlight / receipt / key_card / medicine / diary / photograph / owl_feather / energy`。

终章新增 `film_reel`。当前代码没有 `black_cat_hair` 道具 ID，因此本策划不把“黑猫毛发”作为结局硬条件；若以后另行实现，再作为替代现实锚，不影响本版路由。

### 12.2 每项指标的明确作用

| 指标 | 关内表现 | 结局作用 |
|---|---|---|
| 理智 `sanity` | 低理智会造成镜中动作延迟、控制台假字幕和更强黑边，但不改正确出口 | 理智 ≤20 且现实锚不足进入“无尽噩梦”；理智 >20 才能稳定完成共同拉闸 |
| 体力 `stamina` | 决定可持续冲刺；追逐本身即使低体力也能过 | 撤离与强攻成功率；体力 ≥25 计入 `escapeReady` |
| 线索 `clues` | 决定门厅是否识别现代拼接、控制台能保留多少非首选摘要 | 公开真相要求 ≥70；高线索不能替代具体物证 |
| 团队信任 `trust` | 决定张一诚是否按计划等待信号 | `teamReady` 要求 ≥60 且有实际联络与证据 |
| 好感度 `affection` | 决定白秋是否回应私人约定、R07A/R07B 与感情对白 | ≥45、羁绊和持续尊重行为共同开启“雨停以后” |

### 12.3 每件道具的终章用途

| 道具 | 本关可见作用 | 结局 / 真相作用 |
|---|---|---|
| 胶片 `film_reel` | 门厅必拾取；承载三页剧情链；最终舞台放映 | 证明旧唱段与现代插片属于同一物证；所有正常结局的流程前提 |
| 手电筒 | 后台全黑时照路，可提前看到戏服架后三分透明鬼影 | 不作为结局硬门槛，避免漏拿手电软锁 |
| 借阅小票 | 门厅比对 R-1953 与 23:47 | 受害时间线证据 |
| 门禁卡 | 控制台比对杜学民身份的登录时间 | 人为犯罪证据、安全支援依据 |
| 日记残页 | 证明同类事件跨越多年 | 受害时间线与现实锚 |
| 苏婉老照片 | 辨认镜中苏婉、恢复原唱校对痕迹 | 苏婉保护证据、白秋真相唤醒、共同拉闸核心物 |
| 猫头鹰羽毛 | 固定被篡改的控制台缓存，可选择隔离轨道 | 提供“兼顾部分证据与安全”的第三处理路线；现实锚之一 |
| 护身符 | 抵消镜面或追逐一次强理智伤害 | 可帮助白秋稳定；构成撤离容错，但不会直接换取最佳结局 |
| 镇定药 | 玩家可在最终红点前使用，恢复理智 | 可能越过噩梦与共同拉闸理智门槛 |
| 能量饮料 | 恢复追逐体力 | 构成 `escapeReady`，帮助撤离或强攻 |

### 12.4 前序关键选择

| 前序 / 本关选择 | 终章用途 |
|---|---|
| `baiqiuBond` | 解锁完整关系唤醒、R07A 和感情结局 |
| 论坛后给白秋报平安 | 后续应保存为 `baiqiuReassured`；证明感情线不是终局临时刷出 |
| 向调查者询问如何帮助白秋 | 后续应保存为 `askedHowToHelpBaiqiu`；证明玩家尊重她的主体性 |
| `yichengTrustsYou` | 张一诚愿意按信号支援，而非擅自冲台 |
| 观察林伟坠楼现场 / 六楼窗 | 受害时间线、R06 完整帧、现实锚 |
| 面对苏婉而非立刻逃跑 | 苏婉保护证据与真相唤醒 |
| 启真湖拼证并发送 | 可替代门厅备份的一部分团队准备 |
| 门厅给白秋“先听你说”的承诺 | `theaterPromisedAgency`；感情结局持续尊重条件之一 |
| 后台复制哪一层、如何处理最后一轨 | 直接决定证据组、追逐难度、白秋清醒与结局可达性 |

## 13. 派生条件

### 13.1 三类证据

不允许只靠高 `clues` 获得完整真相：

```text
victimTimeline =
  receipt
  AND (diary OR timeline_linked OR observed_fall_scene)

humanCrime =
  theaterEditLogCopied
  AND (key_card OR checked_fall_window OR searched_medical_vault)

suwanProtection =
  photograph
  AND (theaterOriginalLyricCopied OR memorizedOriginalWarning OR stood_ground_with_suwan)

theaterEvidenceGroupCount =
  victimTimeline + humanCrime + suwanProtection  // 0–3
```

### 13.2 白秋清醒

三条路线任选一条，感情线不垄断基本救援：

```text
relationshipAwake =
  baiqiuBond AND affection >= 30 AND finalCalledBaiqiu

truthAwake =
  suwanProtection AND (finalRestoredWarning OR theaterTargetListCopied)

protectionAwake =
  talisman仍在 AND affection >= 20 AND theaterTargetListCopied

baiqiuAwake = relationshipAwake OR truthAwake OR protectionAwake
```

### 13.3 团队支援与撤离

```text
teamReady =
  trust >= 60
  AND yichengTrustsYou
  AND finalSentSignal
  AND (theaterEvidenceBackedUp OR lakeEvidenceSent)

escapeReady =
  stamina >= 25
  OR energy仍在
  OR talisman仍在
  OR theaterCommandTrackCut
  OR theaterTrackIsolated
```

### 13.4 现实锚

现实锚包括：苏婉照片、日记残页、猫头鹰羽毛、启真湖正确拼证、白秋羁绊、林伟现场证据。统计去重后的数量 `realityAnchorCount`。低理智但现实锚 ≥2 时仍能通关，只增加幻觉，不强制进入噩梦。

## 14. 七种结局

### 14.1 结算优先级

1. 理智 ≤20 且现实锚 <2：无尽噩梦。
2. 白秋未清醒却选择共同拉闸 / 撤离，或强攻全面失败：最后一位观众。
3. 满足高好感度共同拉闸：雨停以后。
4. 满足普通共同拉闸：共赴晨光。
5. 满足完整公开：拨云见日。
6. 成功撤离：远走高飞。
7. 张一诚介入但准备不足：血色兄弟。
8. 其余未覆盖失败：最后一位观众。

### 14.2 路由表

| 结局 | 条件 | 结局真相与结果 |
|---|---|---|
| **雨停以后（感情）** | `finalAction=together`；满足“共赴晨光”；另需 `baiqiuBond`、好感度 ≥45、`baiqiuAgencyRespected`，并且 `baiqiuReassured / askedHowToHelpBaiqiu / theaterPromisedAgency` 至少两项成立 | 白秋主动和张超共同断开轨道，明确回应感情。她之后接受合适的专业支持，但不是被爱情“治好”；两人学会不以“为你好”替对方决定。优先于普通最佳结局 |
| **共赴晨光（最佳）** | `finalAction=together`；`baiqiuAwake`；理智 >20；有老照片；姓名轨已切断或隔离；证据组 ≥2；`baiqiuAgencyRespected` | 白秋自己站起并与张超共同按下舞台总控断开键，苏婉唱词恢复原意，陈九失去转移通道，23:47 循环结束；不要求恋爱关系 |
| **拨云见日（公开）** | `finalAction=broadcast`；`theaterTrackPreserved`；线索 ≥70；证据组 =3；`teamReady` | 完整编辑包与门禁时间同时上传，张一诚和调查者按安全信号进入，陈九被控制；苏婉与林伟的责任被纠正，旧案得以公开 |
| **远走高飞（撤离）** | `finalAction=leave`；`baiqiuAwake`；`escapeReady` | 两人活着离开。若证据组 <2 或没有备份，陈九 / 千绳会根源没有被彻底处理，多年后仍收到 23:47 剧票；若证据充分，至少能阻止同一手法立即重演 |
| **血色兄弟（坏中带胜）** | 张一诚信任玩家但 `teamReady=false`；玩家强攻，或广播失败后陈九冲台；同时体力 <25 或姓名轨仍完整 | 张一诚因不完整信号误判时机，赶来替玩家挡下攻击并牺牲；陈九最终被制服，白秋获救。它由“信任存在、计划缺失”造成，不是随机牺牲 |
| **最后一位观众（坏）** | 白秋未清醒便被强行带走 / 拉闸；强攻时既无体力也无团队；或结算无其他成功条件 | 陈九完成部分转移，张超或白秋成为下一位“演出者”；舞台投影里的观众同时转头，现实观众席仍为空 |
| **无尽噩梦（坏）** | 理智 ≤20 且现实锚 <2，优先结算 | 张超在医院醒来，被告知小剧场从未开放；医生胸前却佩戴真正杜学民的工牌。玩家无法确认自己逃出的是剧场还是另一层剪接画面 |

好结局后仍可按总案判断隐藏尾声“阴阳两界”：林伟记忆完整、苏婉证据完整、保留受害者姓名时，统一尾声结束前多一张林伟与苏婉走过空观众席的图片；它不占七个主结局名额。

## 15. 结局文本与统一尾声

### 15.1 结局展示

- 第二轮行动结算后，直接以现有剧情文字框显示结局标题、完整真相与人物去向。
- 结局文字出现后的前 3 秒禁用继续，保证玩家不会误触跳过。
- 3 秒后允许点击任意位置或按任意键进入统一尾声。
- 结局只用文字框；本轮不要求七套结局 3D 场景。以后若有预算，每个结局最多追加一张图。

### 15.2 统一尾声

统一尾声不强行宣称所有路线都已解决案件，因此好坏结局都可使用。建议四页，每页 3 秒后可点击 / 任意键继续：

> 后来，学校里仍有人讲起那场暴雨。有人说小剧场真的闹鬼，有人说那只是一群人利用传说犯下的罪。每一种说法，都只留下了故事的一部分。
> 苏婉常被叫作女鬼，林伟常被写成意外，白秋常被说成“被救下的人”。可他们不是推动怪谈的道具。他们都曾警告、抵抗、害怕，也都曾试图替自己作出选择。
> 怪谈最可怕的地方，不是夜里是否真的有鬼，而是活人可以借恐惧删掉一句“不要”，抹掉一个人的名字，再把责任留给沉默。
> 如果你在雨里听见朋友叫你，请停下来，确认他还在。不要让任何人独自走到 23:47。

最后淡出标题《浙大夜惊魂》，雷雨声停止，只留清晨第一声鸟鸣。即使是坏结局，这段尾声也把玩家从单纯受惊拉回整部游戏的核心：辨认真相、记住受害者、尊重身边人的选择，并在对方求助时留下来。

## 17. 建模与程序最小需求

### 17.1 不新增的内容

- 不做每个座位的红绳。
- 不坐满 3D 观众。
- 不做保险丝、配电箱、录音机、复杂放映机、机械吊杆或舞台下层。
- 不给苏婉制作完整 3D 动画。
- 不制作多岔路迷宫或藏柜系统。
- 不为每个结局改造一套 3D 场景。

## 18. 检查点、软锁与验收

### 18.1 检查点

1. `theater_reel_collected`：胶片拾取且门厅剧情链完成后。
2. `theater_lights_on`：控制台开关触发、镜灯全部亮起后。
3. `theater_mirror_complete`：三图与游戏跳脸结束后。
4. `theater_pre_chase`：控制台两轮选择完成、追逐即将开始前。
5. `theater_chase_escaped`：玩家越过后台门槛、鬼消失后。

### 18.2 必须验收

- 玩家出生确实位于门厅，暴雨、雷声和闪电只从玻璃外部透入。
- 胶片是开场唯一红点，拾取后有三页同地点剧情链和至少三轮有效选择。
- 每个门厅选择至少影响一个后续字幕、证据组、白秋清醒、团队支援或感情结局条件。
- 主厅门只在门厅剧情链结束后打开。
- 进入主厅的一瞬能看到约 0.4 秒的戏服苏婉舞台闪现，且只触发一次。
- 后台初始入口无门；玩家跨过触发线后门出现并启用碰撞。
- 封门后后台全黑，镜子红光关闭；控制台开关的弱红光保证无手电也不会软锁。
- 按下开关后只有镜灯逐盏亮起，天花板灯始终不亮。
- 相框确实复用白沙模型；三图同机位，每张名义 3 秒，可点击 / 任意键推进；第三图显示满 1 秒后必定触发游戏跳脸。
- 第二剧情点全程用文字转写，不播放或要求制作录音。
- 后台复制层与处理最后一轨是两个独立选择，且各自影响结局。
- 鬼从玩家进后台起就在蓝色三角位置，只是暗且透明；追逐时从戏服架后出来并恢复正常。
- 追逐开始时封门视觉和碰撞同时消失；鬼速度低于玩家冲刺速度。
- 被鬼抓到只触发非阻断跳脸，不停控制、不重置路线、不妨碍继续逃跑。
- 鬼不越过后台门槛；玩家进主厅后鬼消失。
- 追逐后红点准确落在观众席中央；到达后全黑和心跳完整持续 3 秒。
- 红灯全部打向舞台中心；最终图片直接出现在舞台上，每张 3 秒并允许点击 / 任意键推进。
- 放映结束后玩家无需再走动，连续完成两轮终局选择并进入结局文字。
- 结局文字至少显示 3 秒才允许继续，之后所有结局进入统一尾声。
- 高好感度但缺少持续关心 / 尊重行为，不能仅靠最后一次选择进入“雨停以后”。
- 高线索低好感度仍可进入“拨云见日”；低线索高好感度不能公开完整案件。
- 低理智但现实锚足够时仍可通关；理智路线不会随机覆盖证据与关系结算。
- 所有图片走 `assetUrl()`，本地与 R2 路径都能加载。

## 19. 本版锁定结论

- 三块空间、四个主剧情点，后台正好两个。
- 开场只新增胶片一个实体道具；移除旧方案保险丝。
- 门厅用一个物理点承载三页长剧情链，选择分别回流证据、团队、白秋和终局判断。
- 主厅首次进入即闪现穿戏服苏婉图片。
- 后台门采用“先不存在 → 入内后出现封死 → 追逐开始消失”。
- 开灯机关就是现有监控控制台上的微红开关；仅镜灯逐盏亮，顶灯不亮。
- 白沙相框播放三张同机位镜面图，第三张 1 秒后衔接游戏跳脸。
- “被剪过的唱段”只用文字，通过两轮选择决定复制证据与处理最后一轨。
- 复用地下车库幽灵；鬼始终藏在用户蓝色三角处，追逐短、速度慢、碰到只惊吓不阻断逃生。
- 逃回主厅后必须到观众席中央；全黑心跳 3 秒，再以红光和舞台图片完成最终演绎。
- 最终两轮选择结合五项指标、前序道具、前序标记、门厅选择和后台选择解析七个结局。
- 所有结局文字结束后统一进入主题尾声。
