# 农医馆 Blender 初稿

这是“农医馆”（游戏 ID：`medical-library`）的单栋外观几何草模，用来给后续精修打底。

- 保留了游戏地图中的占地比例：`w=3.9`、`d=1.8`、`h=4.6`。
- 采用“低层 podium + 中央高塔 + 入口玻璃脊”的轮廓，入口和立面竖向构件均为独立对象，方便替换。
- 目前只有中性材质和轮廓关系，没有贴图、室内、剧情或碰撞逻辑。
- 直接在 Blender 打开 `medical-library-draft.blend`，按对象名精修；不要改 `building_id` 或游戏占地比例。
